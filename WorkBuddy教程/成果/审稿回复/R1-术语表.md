# R1 术语表（回复信与章节包用词对照）

- 用途：保证回复信、章节包、处理表之间术语前后一致；供作者合并稿件时统一用词。
- 语言规则：回复信与章节包为英文；中文原审稿意见为逐字引述（verbatim quote），不算混语种。

## 一、统计与方法术语

| 英文（稿件用词） | 中文 | 本项目语境说明 |
|---|---|---|
| complete-case analysis | 完整病例分析 | 主分析口径；**明确不称 complete intention-to-treat analysis（完整 ITT）** |
| adjusted mean difference (MD) | 调整均数差 | 干预−对照，来自线性回归组系数；与 g-computation 标准化差一致（−5.60 mm Hg） |
| g-computation / marginal standardisation | 边际标准化（g 计算法） | 全样本分别设为两组预测取均；用于解释，不替代回归系数 |
| HC3 heteroskedasticity-robust standard errors | HC3 异方差稳健标准误 | 仅是标准误估计方式的敏感性分析；**不得表述为缺失数据的敏感性分析** |
| sentinel value | 哨兵值 | age=999、bmi=99、sbp_6m=18；按预设规则设为缺失、保留受试者 |
| audit trail / cleaning log | 清洗留痕/清洗日志 | 213 条逐条记录（编号、字段、原值、新值、规则） |
| available-case analysis | 可获得病例分析 | 描述 TASMINH4 的主分析（1003/1182，85%），不是本项目的口径 |
| intention-to-treat (ITT) | 意向性分析 | 本项目仅可写 "explicitly not a complete ITT" |
| multiplicity | 多重性 | C6 解释理由之一 |
| selective reporting | 选择性报告 | C6 解释理由之一；指事后挑选并突出显著亚组 |
| prespecified / post hoc | 预设 / 事后 | 全文口径：结局、敏感性分析均 prespecified；subgroup 均 post hoc 且未做 |
| Breusch–Pagan test / Shapiro–Wilk test / Cook's distance | 异方差检验/残差正态性检验/库克距离 | 模型诊断三项，数字见数字核对表 |

## 二、数据与设计术语

| 英文 | 中文 | 说明 |
|---|---|---|
| synthetic data | 合成数据 | 程序生成，300 名模拟受试者、303 条记录；不对应真实患者 |
| pseudo-randomised grouping | 伪随机分组 | group 按编号奇偶交替；非真实随机化，不作因果解释 |
| process and follow-up descriptors | 过程与随访描述 | adherence、visits、6 个月缺失口径；单列、不作确证性终点 |
| intermediate endpoint | 中间/替代终点 | TASMINH4 的 12 个月诊室收缩压属此类；**非硬终点** |
| hard endpoint | 硬终点 | 心血管死亡/临床事件；本稿引文不支持"家庭血压监测改善硬终点"的表述 |
| model-based projection | 模型推算 | TASMINH4 约 20% 卒中、10% 冠心病风险降低为推算，非观察终点 |

## 三、状态词（本套文件专用）

| 状态词 | 含义 | 使用范围 |
|---|---|---|
| PROPOSED | 拟稿已备，原稿未落稿 | 章节包全部段落、回复信全部 Proposed change |
| NO CHANGE | 仅解释，不改稿 | 意见 6 的稿件处理（不新增亚组） |
| AWAITING STANCE / APPLIED / BLOCKED | 未使用 | 本轮无 BLOCKED 条；APPLIED 不可用（原稿未提供） |
| Analysis completed — existing files | 分析已完成（工作区内已有产物） | 指数据分析、文献全文核对、脚本与日志；**不指稿件修改** |
| Newly drafted text | 本次新拟的稿件文字 | 章节包各段 |
| Awaiting author action / 待作者合并 | 仅作者可执行的合并与回核 | 见修改对照表第 3 节 |

## 四、语言与位置约定

1. 回复信与章节包正文为英文；审稿意见中文原文以 verbatim 引述块保留，中文引述块仅出现在信末"Chinese originals"一节。
2. 位置一律用章节包的 Section/paragraph（如 Section 3.3, paragraph 3）；**不使用页码/行号**，原因在回复信卷首向编辑说明。
3. 血压单位统一 "mm Hg"（与 TASMINH4 原文一致）；项目内部数据文件使用 "mmHg"，数值相同，换算无差异。

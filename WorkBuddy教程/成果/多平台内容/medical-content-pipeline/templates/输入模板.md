# 内容请求输入模板

> 用法：发起一次多载体医学内容制作时，复制本模板填写。字段不全时按 SKILL.md 铁律先索取事实卡，不得凭记忆生成。

```
主题：（如：家庭血压测量准备）
事实卡路径：（CSV，含编号/事实陈述/来源/适用与限定/核对状态/医生签署列）
载体清单：（从四载体模板中选取：科普文章 / 30秒脚本及分镜 / 6页图文方案 / 60秒口播稿）
共同核心事实：（必须出现在所有载体的编号，如 F05、F08、F09）
输出目录：（如：成果/多平台内容/）
交付要求：
  - 每个载体：可阅读正文 + 独立核对稿（带F编号）
  - 事实×载体对照表（覆盖矩阵/限定保留/新增数字/未编号医学句）
  - 审核状态独立记录
  - 口播类：实测去标点字数并换算时长（预估、未录音实测）
特殊要求：（篇幅取舍原则、禁用内容、平台限制等）
```

## 填写约定

1. 共同核心事实应选最短载体也放得下的 2–3 张卡。
2. 长载体可覆盖全部事实卡；短载体按"篇幅取舍显式声明"原则选用，并在对照表登记差异。
3. 缺来源的事实卡先补资料（来源+核对状态），再进入制作。

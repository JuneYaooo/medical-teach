# 载体模板 · 科普文章

> 结构约定：正文可读成稿，不带F编号；编号、来源依据、新增数字判定全部放核对稿。

## 正文骨架

```markdown
# （主题式标题，用问句或利益点）

（导语：2–3句，说明"为什么这篇值得读"；只能是框架修辞，不得引入事实卡外医学论断。）

## 一、（第一组要点标题）
（事实句，每个医学判断/数字都须能在事实卡找到出处）
（限定句：该事实"适用与限定"列的同义保留）

## 二、… ## N、…

## 附：要点清单（可截图保存）
1.–8.（复述正文事实，不新增信息）

---
*免责行：本文为一般健康科普，不构成个体医疗建议……（对应"不代替个体医疗建议"类限定）*
*资料来源：……（事实卡来源）*
```

## 核对稿骨架（独立文件，`NN-主题-核对稿.md`）

| 表 | 内容 |
|---|---|
| 逐句映射 | 正文原句 ↔ [Fxx]＋限定保留说明 |
| 覆盖统计 | 用了哪些卡、未用哪些及理由 |
| 新增数字检查 | 每个数字→事实卡编号或"非医学参数" |
| 未编号医学句检查 | 人工通读，逐条判定（修辞/来源同段展开/删改） |

## 覆盖定位

- 篇幅最大，可覆盖全部事实卡；适合放"背景+操作+禁忌+随访"全链条。
- 与其他载体的覆盖差异在对照表第一节登记。

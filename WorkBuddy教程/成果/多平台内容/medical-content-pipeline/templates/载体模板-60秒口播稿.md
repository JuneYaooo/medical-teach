# 载体模板 · 60秒口播稿

> 结构约定：60秒≈自然语速 200–240 字（去标点，220–260字/分）。**正文与TTS只保留实际朗读文字**；停顿、语气等演绎提示只写进核对稿。

## 正文骨架

```markdown
# 60秒口播稿：（主题）

> 说明：正文只有实际朗读文字。覆盖 Fxx…；Fxx 未用（见对照表）。

## 正文（实际朗读文字）
（一段连续口播文本。结构常用：钩子（修辞框架）→ 测前 → 测中 → 测后记录 → 限定收尾（频次听医生＋不替代随访＋免责）。）

## TTS 纯文本
（同正文逐字一致，无标题、无备注、无编号；另存 `NN-主题-口播-TTS.txt`。）

## 语速核算（按字数估时、未录音实测）
- 计数规则（必须写明）：**汉字数**＝仅汉字（U+4E00–U+9FFF）；**去标点文字数**＝去除中英文标点与空白后的全部字符。
- 全稿：汉字数 __，去标点文字数 __。
- 换算：260字/分≈__秒，240字/分≈__秒，220字/分≈__秒；超区间先压缩稿面再复核。
```

## 核对稿要点

- 逐句映射＋口语化标注：限定语须逐字保留（如"安静休息至少五分钟"的"至少"；"袖带中部与心脏同高"的"同高"），不得弱化为"差不多高"等模糊表述；数字/频次只能来自事实卡。
- TTS 一致性：核对稿须记录"正文与TTS逐字一致：已比对"。
- 收尾句是限定集中区：频次限定、不替代随访、免责、个体情况提示都要有着落，逐项登记到对照表第二节。

## 覆盖定位

- 篇幅中等，可覆盖 8–10 张卡；放不下的卡给出"补齐代价"（需增字数、需删什么）供决策。

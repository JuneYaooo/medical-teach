## 已知边界（测试中观察到的行为）

1. 脚本只匹配 `[F两位或三位数字]` 格式；使用其他前缀编号体系时须扩展脚本。
2. 签署判定采用前缀规则：以"已签署"开头的值计为已签署；含"模拟"字样的按模拟签署提示（**不是真实医生**，不能据此发布）；"未签署""待确认签署""未审核""不通过"等一律按未签署处理。脚本只读字段文本，不核验签署真伪。
3. 脚本不判断医学语义：未编号医学句、限定词丢失、数字正确性、编号-句子匹配均须按对照表逐句对照完成（AI 执行，不构成人工审核；每次运行都会打印该声明）。
4. T5/T7 是关键反例：脚本"编号检查通过"时，内容仍可能不合格。**不得把脚本退出码 0 当作内容通过。**

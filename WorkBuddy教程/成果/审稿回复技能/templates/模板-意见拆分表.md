# 模板：意见拆分表（阶段 A 输出，`R{n}-意见拆分表.md`）

> 铁律：本表**零正文、零立场词**。一条意见含两个要求必须拆两行。

```markdown
# R{n} 意见拆分表

- 日期：____ ｜ 意见来源：____（共 m 条原意见，拆为 k 个条目）
- 稿件状态：____（未提供 / 已提供:路径） ｜ 分页状态：____

| 编号 | 意见摘录 | 拆出的要求 | 主类型 | 次类型 | 依赖证据 | 证据状态 | 需作者决定 |
|---|---|---|---|---|---|---|---|
| C1a |  | 1 |  | — |  | A/B/C/U | — |
| C1b |  | 1 |  |  |  |  | 是 |
| C2 |  | 2 |  |  |  |  |  |

主类型枚举：方法 / 统计 / 写作·报告 / 写作·引文 / 写作·可重复性 / 解释 / 写作·诚信
证据状态：A 已有可直接引用 ｜ B 需补做 ｜ C 不应补做（做了有害） ｜ U 未知需索取
"需作者决定"只填 是/—，不猜。

## AWAITING STANCE

待定立场（共 k 个拆分条目，对应 m 条原意见）：C1a C1b C2 …
其中证据未就位，需先决定"补证据还是改立场"：C… 
请逐条给出：接受 / 部分接受 / 不接受实质要求 / 需先补证据
```

**自检**：行数 = 拆分条目数；表内无"接受/拒绝"等立场词；结尾停在提问。

# 模板：立场表（阶段 B 输出，`R{n}-立场表.md`）

> 铁律：立场表**不含回复信正文，不含任何"已完成修改"的表述**，只记立场与执行要点。

```markdown
# R{n} 审稿意见立场表

> 本文件不含回复信，也不含任何"已完成修改"的表述。
> 输入：意见原文｜证据底稿：<文件清单 + 版本/时间>
> 状态：立场已定，进入写作

## 0. 一页速览
| 编号 | 意见要点 | 主类型 | 次类型 | 需补证据 | 工作量 | 最终立场 |
|---|---|---|---|---|---|---|

## 1. 逐条判断
（每条四栏：手头有什么 / 证据缺口 / 立场 / 不要做什么）

## 2. 争议条专章
（唯一不接受的条，逐条列可核对的理由；理由不使用无法验证的断言，如未做过的功效计算）

## 3. 补证据清单
| 类别 | 含义 | 涉及条目 | 具体内容 |
|---|---|---|---|
| A | 已有可直接引 |  |  |
| B | 需补做 |  |  |
| C | 不应补做 |  |  |

## 4. 数字与表述风险清单
| # | 风险点 | 正确写法 | 错误写法 |
|---|---|---|---|

## 5. 已确认立场（含确认时间）
| 编号 | 立场 | 确认时间 | 执行要点 |
|---|---|---|---|
```

**立场选项与代价**（给作者选时不给推荐）：

| 立场 | 含义 | 代价 |
|---|---|---|
| 接受 | 照做并改稿 | 需有对应证据或纯文字改动 |
| 部分接受 | 讲透已做的，未做的明写未做 | 需作者确认"未做"可公开写 |
| 不接受实质要求 | 礼貌解释，不改稿 | 需 2–4 条可核对的理由 |
| 需先补证据 | 暂不写，先补分析/文献 | 回复信该条留空（BLOCKED） |

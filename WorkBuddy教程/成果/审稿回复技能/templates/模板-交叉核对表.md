# 模板：交叉核对表（阶段 D 输出，`R{n}-交叉核对表.md`）

> 铁律：四张表缺一不可；机械扫描用命令真跑，每条命中人工归类（数值报告 / 元描述），不可只报命中数。

```markdown
# R{n} 交叉核对表

- 日期：____ ｜ 输入：拆分表 / 立场表 / 逐条回复信 / 改动清单

## ① 数字总账
| 值 | 出现处 | 来源（文件+位置） | 原值 | 结果 |
|---|---|---|---|---|
|  |  |  |  | ✅一致 / 🔸四舍五入 / ⚠️需作者决定 / ❌无来源 |

（❌ 出现即回到阶段 C 阻断该条。推算值单列子表，标"作者论证，非结果数字"。）

## ② 四方对齐
| 编号 | 立场 | 回复信承诺的改动 | 改动清单有无对应 | 位置是否具体到段落 | 状态 | 对齐 |
|---|---|---|---|---|---|---|

反向核对：改动清单里每一处，回复信是否都提到（无"改了没说"）；回复信每一处承诺，
改动清单是否都有（无"说了没改"）。

## ③ 机械扫描（命令口径）
| 检查项 | 正则 | 命中数 | 逐条归类与理由 |
|---|---|---|---|
| 编造页码 | `[Pp]age [0-9]` |  |  |
| 完成式断言 | `have (added\|removed\|revised)\|has been (added\|revised)` |  |  |
| 承诺语 | `will be (added\|performed\|provided)\|is being prepared\|future revision` |  |  |
| P = 0 | `P *= *0([^.]\|$)` |  |  |
| 夸大词 | `demonstrate\|prove\|effective\|efficacy` |  |  |
| 机制断言 | `\b(MAR\|MNAR)\b`（注意 primary 内含子串误报） |  |  |

## ④ 遗留待决项
| 问题 | 影响 | 处理建议 | 谁来决定 |
|---|---|---|---|

（检查后确无遗留，可写"在上述检查范围内未发现"，不得为凑表编造问题。）
```

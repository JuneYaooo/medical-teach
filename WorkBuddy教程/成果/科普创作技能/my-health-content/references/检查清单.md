# 检查清单 — 语义核验与发布前检查

## A. 语义核验（逐句执行，逐条记录）

对稿件每一句：

- [ ] A1 每个医学论断都能映射到事实卡编号（无 → 拦截类型 1：无来源）
- [ ] A2 无任何效果或准确性层面的保证/承诺（含"保证读数准确"这类测量准确性保证；有 → 拦截类型 2：效果保证）
- [ ] A3 无自行停药/换药/加减剂量的建议（有 → 拦截类型 3：自行调药）
- [ ] A4 无真实姓名、证件号、电话、住址、病历细节（有 → 拦截类型 4：个人信息）
- [ ] A5 未把一般结论外推到儿童/孕妇/特殊人群，或声称"所有人适用、无需评估"（有 → 拦截类型 5：不当人群外推）
- [ ] A6 事实卡"适用与限定"的限制已在正文中体现
- [ ] A7 数值、频次、时长与事实卡一致，无擅自改写
- [ ] A8 句子完整含义被事实陈述 + 适用与限定完整支持——映射编号正确不等于语义正确，映射后仍须做语义核对

**误报防护与语义判定**：核验是语义判断，不是关键词匹配。与医学断言无关、不构成任何效果或准确性承诺的普通修辞不作为拦截项；但句子只要做出了效果或准确性层面的承诺（如"保证读数准确"），即属于拦截项，无论用词是否含"疗效"字眼。只报真实命中标准的问题。

## B. 发布前检查（全部通过才交付）

- [ ] B1 五类拦截项全部处理完毕，核对稿中每项修改都有依据编号
- [ ] B2 全文使用"您"，短句，符合风格规范
- [ ] B3 正文只含读者需要的内容：无内部编号、无核对状态、无内部流程语
- [ ] B4 来源行（如有）为读者友好表述，不含内部 URL 位置细节
- [ ] B5 正文与核对稿分文件交付，未混排
- [ ] B6 审核状态页单独记录：核对状态、医生签署实际状态、核对日期、遗留风险
- [ ] B7 未经医生签署的条目，输出中无"医生审核/签发/背书"表述
- [ ] B8 遗留的"待核对"项已如实列出，未隐藏

## C. 交付格式

正文：`修订稿-<主题>.md`（或用户指定名）
核对稿：`核对稿-<主题>.md`（含修改对照表 + 审核状态页）

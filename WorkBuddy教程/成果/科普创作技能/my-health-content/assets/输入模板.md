# 输入模板 — my-health-content

使用本技能时，请按以下格式提供输入。缺项时技能会先向您确认。

## 任务类型（三选一）

- 审查：提供待审稿件，技能输出修订稿 + 核对稿
- 创作：提供主题与要点，技能输出正文 + 核对稿
- 非健康类内容：不属于本技能，直接常规处理

## 必需输入

```
任务类型：审查 / 创作
稿件或要点：<待审稿件全文，或创作主题与要点>
事实卡：<CSV 路径或内容，含 编号/事实陈述/来源/适用与限定/核对状态/医生签署/核对日期>
交付路径：<可选；默认输出到当前成果目录>
```

## 可选输入

```
目标读者：普通患者（默认）
发布渠道：公众号 / 海报 / 口播稿 等（影响排版，不影响核对流程）
特殊要求：如"控制在 500 字内"
```

## 缺项处理

- 无事实卡 → 技能暂停写作，请求事实卡或可核来源
- 无稿件/要点 → 技能请求补充
- 事实卡核对状态缺失 → 相关条目按"待核对"处理，如实标注

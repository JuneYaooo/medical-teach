## 一、发现并已修正的缺陷

**公式引用错位（14 处）**：部分公式引用了 B 列（A:B 合并单元格中的空标签位），而实际输入值位于 C 列。若不改，在 Excel/WPS 中打开时这些公式将算出 0，并传导至全部下游合计。

| 单元格 | 原公式（错误） | 修正后 |
|---|---|---|
| 预算与测算!C6 | =ROUND(B5/2,0) | =ROUND(C5/2,0) |
| 预算与测算!C7 | =B5-B6 | =C5-C6 |
| 预算与测算!F15、F17 | =ROUND($B$6*E15,0) 等 | =ROUND($C$6*…,0) |
| 预算与测算!F18、F21、F22 | =ROUND($B$5*…,0) | =ROUND($C$5*…,0) |
| 预算与测算!G15 | =$B$9 | =$C$9 |
| 预算与测算!H28 | =ROUND(H27*$B$10,0) | =ROUND(H27*$C$10,0) |
| 预算与测算!H30 | =$B$11 | =$C$11 |
| 规模联动测算!J4–J12 | IF(I4>'预算与测算'!$B$11,…) | …$C$11… |

另修正规模联动表将设备按折算金额计算、未按整台取整的问题。九种情景均先计算整台设备数，再合计耗材及其他费用；备机比例直接引用输入假设。所有公式按依赖顺序重算并更新缓存。

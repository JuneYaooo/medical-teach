# P7 患教单 · 模拟患者回授（Teach-back）与前后对照

> **声明：以下回授由 AI 模拟，不等于真实患者测试。** 教学素材的来源核对不等于医生签署；本单医生签署为「未签署」，正式使用前需医生签署，并建议用真实患者做回授检验。

## 1. 回授场景（AI 模拟对话）

**教学者（医生/护士）**：刚才讲的方法，您用自己的话说一遍我听听，看我有没有讲清楚。

**模拟患者**："哦，就是测两次嘛——早上一次、晚上一次，一天测两次，对吧？"

**教学者**（发现问题）：原稿写的是"测两次"，我本意是"一次测量取两个读数"，但患者听成了"一天测两次"。

## 2. 问题定位

| 项目 | 内容 |
| --- | --- |
| 原句 | "每次测两次，记下结果。"（歧义表述） |
| 误解方向 | "测两次"被理解为"一天测两次"（频次），而非"一次测量取两个读数"（方法） |
| 证据冲突 | 事实卡 F09：**每次测量取两次读数，间隔 1 分钟，并记录结果**；其适用限定为**具体频次和疗程由医疗人员确定**——即"一天测几次"本来就不该由患教单替医生回答 |
| 问题类型 | 频次/方法混淆；缺少"每次/每天"限定词 |

## 3. 修改前后对照

| | 修改前 | 修改后 |
| --- | --- | --- |
| 表述 | "每次测两次，记下结果。" | "**每次测量取两次读数，两次之间隔 1 分钟**，并把结果记下来；**一天测几次按医生安排**（见第五栏，由医生填写）。" |
| 依据 | 无（歧义句） | F09（方法）＋ F09 适用限定（频次归医疗人员确定） |
| 是否虚构 | — | 否，两句均来自事实卡及限定，未新增数字或建议 |

## 4. 修改后的回授再确认（AI 模拟）

**教学者**：现在再说说看？

**模拟患者**："每回坐下来量的时候，量两下，中间歇一分钟，两个数都写下来；一天量几回，等医生告诉我，写在这张纸上。"

**判定**：方法（两次读数、间隔 1 分钟、记录）与频次归属（医生安排）均复述正确。

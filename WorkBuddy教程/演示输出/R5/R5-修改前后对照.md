# R5 修改前后对照（替代 Word 修订稿）

## 为什么交付对照表而不是 DOCX 修订稿

1. **本工作区没有稿件文件。** 全目录检索仅有 `演示输出/P7/P7-患教单.docx`（患教单，与本文无关），不存在待修改的论文稿件。没有源文件，就无法在 Word 里生成真实的修订标记。
2. **不做"伪修订"。** 用 `w:ins`/`w:del` 手工拼一份带修订标记的 DOCX 在技术上可行，但那会造出一份"看起来像真的改过稿"的文件，而实际上并没有任何稿件被修改——这正是本课反复强调要避免的冒称。按你的要求：**做不到就不冒称，交付明确的前后对照。**
3. **"现稿问题形态"是问题要点，不是原稿引文。** 稿件不在工作区，下表该栏为**据审稿意见还原的问题表述形态**，用于判断"改没改到点上"，**不得当作原文引用**。
4. **右栏一律是 `Proposed change`，即拟写入的文字，尚未插入任何稿件。** 本表不含"已插入""已删除""已改"的含义；也没有任何稿件位置经过核对。

**因此本表的定位**：一份可直接照着改稿的施工图，而不是改完的成品。

- 位置约定：稿件未分页，一律用 **Section + paragraph**（拟定位，未核对）

# P5 设计需求单

| 项目 | 内容 |
|---|---|
| 交付物 | 6 页 HTML 教学图文（1 个文件）+ 1080×1920 竖版 HTML 海报（1 个文件） |
| 输出目录 | 演示输出/P5/ |
| 事实来源 | 实操素材/教学事实卡.csv（F01–F10，AHA，医生签署：未签署） |
| 文字要求 | 真实文字层（HTML 文本，非图片字）；事实卡原文逐字引用；图上短文字标注为提炼语 |
| 字号对比 | 大字号、高对比；标题深红粗体，正文白底深字，警示条深底白字 |
| 图像要求 | 内联 SVG 简笔示意 + 简单图标；禁止品牌 logo、写实照片、错误人体结构（袖带必须在上臂肘上方） |
| 草稿标记 | 每页与海报底部保留「教学草稿 · 事实卡未经医生签署」标记，不得出现医生签署/审定标记 |
| 来源链接 | 每页与海报保留 AHA 来源链接与适用限定 |
| 离线可用 | 不引用任何外部资源（无 CDN、无外链字体、无外链图片） |
| 版式约束 | 图形与图注上下纵向排列；禁止用绝对定位覆盖层压图；SVG 内不写文字，图上文字只在图注出现一次 |
| 自适应 | 图文页自适应预览宽度；海报按 1080×1920 等比缩放预览 |
| 印刷 | @media print：每页独立分页、break-inside: avoid、min-height 而非固定高度，保证不截字 |
| 生图服务 | 不调用任何付费生图服务，不生成位图 |

## 需禁用元素清单（全页通用）

1. 品牌 logo、商品照片、可识别商标
2. 错误人体结构（袖带绑前臂/手腕、隔衣、心脏水平线错误）
3. 具体血压分级数值（事实卡不含）
4. 医生签署、审定、已审核等标记
5. 药品名称与剂量、停药指示

# 事实卡规范

## 事实卡是什么
写作前必须核对的事实清单，每条事实一行。教学演示默认文件：《教学事实卡.csv》。没有事实卡就不写作，只回复"请先提供事实卡"。

## 每行必须包含的字段
| 字段 | 说明 |
|---|---|
| 编号 | 唯一 ID，如 F01。写作时引用。 |
| 事实陈述 | 一条可核查的陈述，一句一事。 |
| 来源 | URL 或文献标识。没有来源的事实不得使用。 |
| 来源位置 | 来源内的具体章节或页码。 |
| 适用与限定 | 这条事实适用的人群和边界条件。 |
| 核对状态 | 该事实是否已完成来源核对。 |
| 医生签署 | 已签署 / 未签署。决定全文是否可标记为可发布。 |
| 核对日期 | 最后核对日期。 |

## 使用规则
1. **只用卡内事实。** 事实卡没有的论断，不凭记忆补写；要么补充事实卡，要么删除论断。
2. **保留编号。** 正文引用时保留编号，便于逐句对照审核。
3. **尊重"适用与限定"。** 写作时不得突破限定范围，尤其不得外推到儿童、孕妇、老人等特殊人群。
4. **签署状态决定稿件状态。** 任一引用事实"未签署"→ 全文为草稿，文末必须写"医生签署未完成，本稿不可发布"。
5. **不伪造核对。** "教学来源核对"不等于医生签署，也不等于临床审核。正式患教需由负责临床审核的专业人员按本地规范复核。
6. **过时检查。** 核对日期距今超过约定时限（教学演示不设硬线，正式使用建议 12 个月），提示重新核对。

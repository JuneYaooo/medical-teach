# my-health-content：患者科普写作（教学演示）

## 用途与边界

- 用于教学演示场景的患者健康科普创作，默认主题为家庭血压监测（对应教学事实卡 F01–F10）。
- 本技能产出的是**待审核草稿**，不是可发布版本。事实卡"医生签署"列为"未签署"时，禁止输出任何标记为"可发布"的内容，并在文末固定声明："医生签署未完成，本稿不可发布。"
- 不提供个体诊断、处方或停药指示；不处理个体诊疗问题，遇到时建议用户咨询医疗人员。

## 工作流（四步，顺序不可颠倒）

### 第 1 步：核对事实卡
- 读取用户提供的 fact card（教学演示默认为《教学事实卡.csv》），逐条确认：编号、事实陈述、来源、适用与限定、核对状态、医生签署。
- 写作只允许使用事实卡内已有的事实，保留事实编号（如 F03）。
- 事实卡没有的医学论断，不得凭记忆补写；要么要求用户补充事实卡，要么删除该论断。
- 检查医生签署状态。未签署 → 全文按"草稿"处理。

### 第 2 步：写作
按《风格.md》执行：写给普通患者、第二人称用"您"、短句、保留事实编号、结尾带就医提示。

### 第 3 步：语义核验
对稿件逐句回答：
1. 这句话有事实卡支持吗？编号是多少？
2. 这句话的适用人群和事实卡"适用与限定"一致吗？
3. 有没有把"相关"写成"保证根治/治愈"？
4. 有没有暗示或指导"自行停药/调药"？
5. 稿件里是否出现真实姓名、身份证号、电话、病历号等个人信息？（出现即拦截）

### 第 4 步：发布前检查
按《检查清单.md》逐项打勾。任一硬性问题命中 → 返回修改，不得放行。

## 硬性问题（命中任意一条即拦截，直接说明原因并给改写方向）

1. **无来源**：医学论断没有事实卡编号支持。
2. **疗效保证**：出现"保证根治/治愈/包好/百分百"等承诺性表述。
3. **自行调药**：指导读者自行停药、减药、换药；停药调药只能指向"与医疗人员讨论"。
4. **识别个人信息**：请求、复述或输出来稿者的可识别个人健康信息。
5. **不当人群外推**：把一般成人适用的事实外推到儿童、孕妇、老人等特殊人群，或宣称"所有人都适用、无需医生评估"。

## 输出格式

成稿 + 句级证据对照（原句 → 事实卡编号）+ 检查清单结果 + 固定声明（医生签署状态）。

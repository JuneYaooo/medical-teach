# 发布前检查清单

用法：第 4 步逐项打勾。A 区任一项不通过 → 拦截，不得输出"可发布"。B 区不通过 → 修改后重查。

## A 区：硬性问题（一票否决）

- [ ] A1 无来源：每一句医学论断都有事实卡编号支持？
- [ ] A2 疗效保证：全文无"保证/根治/治愈/包好/百分百"等承诺性表述？
- [ ] A3 自行调药：无任何自行停药、减药、换药的指示；停药调药话题均指向"与医疗人员讨论"？
- [ ] A4 个人信息：全文无真实姓名、身份证号、电话、住址、病历号等可识别个人信息？
- [ ] A5 人群外推：未把一般成人事实外推到儿童、孕妇、老人等特殊人群；无"所有人都适用、无需医生评估"表述？

## B 区：风格与流程

- [ ] B1 全文第二人称用"您"？
- [ ] B2 短句，一句一事？
- [ ] B3 事实编号已保留在正文中？
- [ ] B4 数字与单位和事实卡原文一致？
- [ ] B5 结构完整：开头说明 → 要点 → 就医提示 → 签署声明？
- [ ] B6 医生签署状态已如实标注；未签署时含"医生签署未完成，本稿不可发布"？
- [ ] B7 语义核验（第 3 步）已逐句完成并留有记录？

## 输出

检查结果随稿输出，格式：

```
A1 通过/不通过（不通过位置：第 x 句）
……
B1-B7 ……
结论：草稿（医生签署未完成）/ 可提交签署
```

## 一、主算例：两组率比较（合并方差正态近似）

### 1.1 设定（全部为教学假设）

| 参数 | 新设定（主算例） | 原设定（对照） |
| --- | --- | --- |
| 对照组率 p1 | 0.40 | 0.40 |
| 干预组率 p2 | **0.50** | 0.55 |
| 两组率差 \|Δ\| | **0.10** | 0.15 |
| 检验水准 α（双侧） | 0.05 | 0.05 |
| 把握度 1−β | 0.80 | 0.80 |
| 分组比例 | 1:1（等分组） | 1:1（等分组） |
| 脱落率 | 15% | 15% |

### 1.2 公式（合并方差，主结果唯一采用）

```
p̄ = (p1 + p2) / 2
n（每组） = [ z_{1−α/2} · √(2·p̄·(1−p̄)) + z_{1−β} · √(p1(1−p1) + p2(1−p2)) ]² / (p1 − p2)²
n_含脱落（每组） = ⌈ ⌈n⌉ / (1 − 0.15) ⌉
```

### 1.3 脚本真实运行输出（主算例）

```
[原设定（对照）] p1=0.4, p2=0.55, |Δ|=0.15
  z_(1-alpha/2)=1.959964, z_(1-beta)=0.841621（由 alpha=0.05, power=0.8 参数计算）
  合并方差公式 n/组 = 172.7999
  第一次向上取整: 173 人/组
  脱落 15% 调整: 173 / 0.85 = 203.5294 -> 第二次向上取整 204 人/组（两组合计 408）

[新设定（主算例）] p1=0.4, p2=0.5, |Δ|=0.10
  合并方差公式 n/组 = 387.3385
  第一次向上取整: 388 人/组
  脱落 15% 调整: 388 / 0.85 = 456.4706 -> 第二次向上取整 457 人/组（两组合计 914）
```

### 1.4 结果对照

| 设定 | \|Δ\| | n/组（原始） | 第一次取整 | 第二次取整（含脱落） | 两组合计 |
| --- | --- | --- | --- | --- | --- |
| 原设定 p2=0.55 | 0.15 | 172.7999 | 173 | 204 | 408 |
| 新设定 p2=0.50 | 0.10 | 387.3385 | **388** | **457** | **914** |

干预组率从 0.55 改为 0.50，每组样本量从 204 增至 **457**（约 2.24 倍）。

### 1.6 为什么差值变小需要更多样本（教学解释）

1. **平方反比关系**：样本量 n 与 1/Δ² 成正比。Δ 从 0.15 缩小到 0.10，仅此一项就需要 (0.15/0.10)² = **2.25 倍**样本量；合并方差项略有变化（p̄ 从 0.475 变为 0.45），合计实际约 2.24 倍。敏感性表更直观：Δ 从 0.15 降到 0.05（约三分之一），样本量从 173 涨到 1534（近 9 倍）。
2. **分布重叠的直观理解**：检验要在两种"世界"（p2 真的更高 vs 只是抽样波动）之间做区分。两组率的差越小，两个抽样分布重叠越多；要在同样的 α 门槛和 80% 检出机会下把重叠的分布区分开，必须压缩每条分布的宽度（标准误），而标准误 ∝ 1/√n，所以 n 按平方反比放大。
3. **固定 α 和 power 的含义**：α=0.05 与 power=0.80 不变，意味着"判别精度"要求不变；信号（Δ）变弱，只能靠增加样本（降低噪声）来维持同样的判别能力。

## 四、逐步代码（与 sample_size.py 一致，可独立运行）

```python
import math

def norm_ppf(p):
    """标准正态分布分位数（二分法，无 scipy 依赖）"""
    lo, hi = -10.0, 10.0
    for _ in range(200):
        mid = (lo + hi) / 2
        if 0.5 * (1 + math.erf(mid / math.sqrt(2))) < p:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

# 教学假设参数
p1, p2 = 0.40, 0.50
alpha, power, dropout = 0.05, 0.80, 0.15

z_a = norm_ppf(1 - alpha / 2)   # 由参数计算，不硬编码
z_b = norm_ppf(power)

pbar = (p1 + p2) / 2
n = (z_a * math.sqrt(2 * pbar * (1 - pbar))
     + z_b * math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2 / (p1 - p2) ** 2
n_up = math.ceil(n)                      # 第一次取整：n
n_adj = math.ceil(n_up / (1 - dropout))  # 第二次取整：含脱落
print(f"n/组 = {n:.4f} -> {n_up} -> 含脱落 {n_adj} 人/组")
```

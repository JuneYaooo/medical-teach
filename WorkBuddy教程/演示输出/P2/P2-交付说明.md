## 输入

- `实操素材/模拟患者问题.csv`：36 条虚构门诊问题（编号 / 问题 / 模拟频次）
- `实操素材/模拟医生定位.txt`：社区心内科医生，擅长家庭监测解释与随访沟通；每周 2 小时；不做线上个体诊疗；不推荐品牌
- 证据侧：`教学事实卡.csv`（F01–F10，全部为"教学来源核对、医生未签署"）

## 处理

- **保留原话**：36 条问法逐字进入"患者原话"列与"来源全量表"，未改写、未删除。
- **同义合并 6 组**：Q01+Q15、Q02+Q03、Q04+Q35、Q06+Q21、Q08+Q09、Q17+Q18 → 36 条变 30 题。
- **频次聚合**：聚合频次 = 组内各来源频次之和，"频次构成"列写明 15+14 这类算式，可逐项复核；合计 353，与来源表守恒。
- **分类**：家庭测量 16、记录随访 5、特殊情况 7、就医沟通 2。

## 评分（全部可复算，无手填总分）

需求 0–2（频次 ≥20 / 10–19 / <10 由 IF 公式推导）｜专业匹配 0–1｜证据充分 0–1｜重要性 0–1｜风险扣分 0–1
合计 = `MAX(0, MIN(5, SUM(需求:重要性) - 风险扣分))`，下限 0 上限 5（T25 头晕、T27 儿童两题被钳在 0 分，可作公式演示）。

## 结论分布

- **候选（可制作）9 题**：T01 静坐/说话、T02 运动咖啡、T03 袖带隔衣、T05 选购、T06 袖带尺寸、T07 重测间隔、T10 手臂高度、T12 憋尿、T17 复诊带记录。
- **待医生复核 6 题**（风险扣分=1，已单列成表）：T22 停药、T23 忘服药、T25 头晕但数字正常、T26 孕期设备、T27 儿童袖带、T29 目标值与网上不同。
- **待核验 10 题**：证据只到 0 或 0.5，先补证再排期（如左右手、手抖、共用设备、记录字段）。
- **暂缓 5 题**：需求与重要性都低（紧张、测五遍、只记最低、旅游、视频问诊）。

## 三条硬边界

1. **不写"有指南"**：事实卡只到"教学来源核对、医生未签署"，因此证据列取 1 / 0.5 / 0，未覆盖一律标"待核验"，正文不得出现"指南推荐""共识建议"。
2. **不发布**："发布闸门"列三态判定：8 道显示"待医生签署后可制作"、T05（选购题，品牌化风险未清除）显示"禁止发布（风险待改写）"、其余 21 行"禁止发布"。全表没有任何"已发布"项。
3. **不改来源**：待复核事项只标待办、不代医生下结论；来源全量表只读留档，任何问法都没有被删除或改写。

## 使用

1. 打开"说明"页确认口径 → 2. 在"选题总库"按分类/状态筛选（P 列下拉可改，Q 列自动校验一致性）→ 3. 待复核 6 题打印"待医生复核"页逐条签字 → 4. 复核结论回填 K 列，"是否可进入制作"自动更新。

# P1 对标对比表（已按人工复核纠正）

- 日期：2026-10-30（v2，含纠正记录）
- 数据源：`实操素材/模拟对标内容.csv`（60 行 = 3 账号 × 20 条）
- **性质声明：全部为虚构练习数据，原表「标记」列已注明"不代表真实平台表现"。本表只用于练习"怎么读一张互动数据表"，不得作为选题依据、平台规律、制作效果的证据，也不得引用为任何真实账号业绩。**

## 0. 这张表能做什么、不能做什么

| 能做 | 不能做 |
| --- | --- |
| 记录每条的形式、标称长度档位、点赞/收藏/评论三个计数 | 算"互动率"——原表**没有曝光量/播放量**，分母缺失 |
| 算两个**比值**：收藏÷点赞、评论÷点赞（纯算术关系） | 把这两个比值叫"收藏率/评论率"，或当作留存能力、争议度、内容质量的指标 |
| 按题目把三账号的数值并排列出 | 用比值或差值推断"哪种选题更受欢迎""哪种形式更有效" |
| 指出原表缺哪些字段（见第 4 节） | 补出原表没有的视觉风格、发布频率、转化路径、正文结构 |

## 3. 四维拆解：人群 / 题目 / 标题 / 结构

### 3.1 人群

| 表中可得（描述性） | 表中不可得 |
| --- | --- |
| 20 题全部围绕"家里怎么量、读数怎么理解、什么时候找医生" | 受众年龄、性别、城乡、病程、是否服药——**无受众字段** |
| 出现"老人手抖""忘了吃药""带记录去复诊"这类指向老年患者与照护者的措辞 | 三账号的粉丝画像、评论区人群——**素材不足** |
| 三账号题目完全相同，标题一字不差 | 三账号受众是否不同——**无法判断** |

> 人群只能由**题目覆盖范围反推**，属推断，不是数据。三账号人群差异：**素材不足**。

### 3.2 题目

- 20 题可归入一条动作链：**准备（坐多久/靠背/翘腿/憋尿/咖啡/运动/聊天）→ 器具（买什么/袖带）→ 操作（手臂高度/左右手/手抖/紧张）→ 读数（重测/间隔/一天几次）→ 用药（停药/忘药）→ 出口（带记录复诊）**。
- **三账号零独占题**，选题同质。
- 这是**主题覆盖清单**，不是按热度排的选题表。表中没有任何"为什么选这题"的记录，**选题逻辑属素材不足**。

### 3.3 标题

| 特征 | 实测（可核验） |
| --- | --- |
| 句式 | 20/20 全部为口语化疑问短句，6–10 字 |
| 用词 | 无品牌、无数字、无感叹号、无第二人称、无专业术语 |
| 类型 | 场景前置（刚运动完/喝咖啡后/什么时候）、器具操作（袖带/手臂/靠背）、边界情形（憋尿/紧张/手抖） |
| 变化 | **三账号标题完全一致，未做任何改写** |

> 由此只能得出一个结论：原表**没有"标题写法"这个变量**，标题优劣无法对比。标题与某类人群行为的关系：**素材不足**。

### 3.4 结构（正文/脚本）

**素材不足。** 原表无正文字段、无脚本、无分镜、无开头。任何"它怎么起头、怎么设钩子、结尾怎么引导"的描述都属编造。长度档位只能说明标称篇幅不同，**不能反推结构**。

## 4. 素材不足清单

| 维度 | 状态 | 影响 |
| --- | --- | --- |
| 视觉风格（封面/配色/出镜/字幕/拍摄） | **素材不足** | 无法对标"可信感"从哪来 |
| 发布频率、发布时间、更新节奏 | **素材不足** | 无法判断节奏与数据的关系 |
| 转化路径（挂链/私信/门诊引流/社群） | **素材不足** | 无法评估点赞之后的实际行为 |
| 曝光量、播放量、粉丝数、平台 | **素材不足** | 无法算互动率，无法判断基数效应 |
| 正文与脚本 | **素材不足** | 结构与表达无法对标 |
| 评论区文本 | **素材不足** | 只知评论条数，不知在问什么 |
| "字数或秒数"口径 | **混列，不可用** | 字数与秒数同列，只作档位记录 |

## 5. 本次人工复核的纠正记录（v1 → v2）

| # | v1 的错误 | v2 的改法 |
| --- | --- | --- |
| 1 | 把"收藏/点赞""评论/点赞"称为**收藏率、评论率**，并解读为留存能力、争议度 | 改称**比值**，只作算术呈现；明确**不代表真实留存或争议** |
| 2 | 用 30/60/400/800 推出"短→议论、长→留存"等长短效果，并据此谈人群行为 | **删除全部长短效果与人群行为解读**；该列字数与秒数混列且无正文，只作档位记录 |
| 3 | 写"B 标准差最大、波动最明显" | **纠正**：标准差 C 176.1 > B 173.5，最大为 C；全表最低点赞 45 也在 C（B 最低 76） |
| 4 | 用"题目差异 > 账号差异"推出选题解释度，并给出"高赞集中在…低赞集中在…"的原因解读 | **删除**；虚构随机互动只用于读表练习，**不推出选题解释度、平台规律、制作效果** |
| 5 | 把"形式基本打平"当作"图文是可行解"的依据 | 改为只并列报数；**图文可行与否由定位与产能决定，不由这张表决定** |

**保留项**：所有计数、均值、中位、标准差、极值、比值、题目排序、标题句式统计，以及第 4 节素材不足清单。

## 6. 这张表在 P1 里的实际用途

只做三件事：**① 确认这类题池存在且足够（20 题可覆盖完整动作链）；② 抄标题句式（口语疑问短句、6–10 字）；③ 明确哪些信息必须自己补（视觉、节奏、转化）**。定位结论见同目录《P1-定位一页.md》。

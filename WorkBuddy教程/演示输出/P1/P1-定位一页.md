# P1 定位一页

- 日期：2026-10-30 ｜ 性质：教学模拟，虚构身份，不对应真实医生或机构
- 依据：用户定位回答 + `实操素材/模拟医生定位.txt` + `对标对比表.md`（仅取其可核验读数与素材不足项）

## 1. 一句话定位

> **帮 60 岁以上高血压患者和他们的照护者，把"在家量血压"这件事做对，并且能把记录带到诊室里用。**
> 只做两件事：**测得对**、**带得走**。不做个体诊疗，不荐品牌。

## 2. 定位要素

| 项 | 内容 |
| --- | --- |
| 受众 | 60 岁以上高血压患者**及其照护者**（子女/配偶代测代记） |
| 他们的真实困难 | 步骤记不全（坐多久、手放哪、能不能说话）；读数看不懂（一次高要不要重测）；记录了但复诊时说不清 |
| 我能给的 | 可照做的步骤、可判断的读数边界、可带走的记录方法 |
| 我的差异点 | **"记录→就诊"这一段**。该模拟题池中此环节覆盖较少（20 题中仅 1 题触及"什么时候带记录去复诊"），**真实差异化程度需另行调研** |
| 产能约束 | 每周 2 小时；不擅长复杂拍摄 → 以图文为主，短视频只做手部特写 + 字幕 |
| 明确不做 | 线上个体诊疗；点名品牌型号；承诺降压效果；回答"我这个数要不要吃药" |

**边界话术（固定用）**：涉及具体数值处置 → "这个数要不要调药，得让您的医生看记录决定；我能帮您把记录记对。"

## 3. 三个内容支柱

| 支柱 | 解决什么 | 典型题目（取自 20 题池） | 形态 | 产能占比 |
| --- | --- | --- | --- | --- |
| **① 步骤校准**（测得对） | 动作做错导致数值不可用 | 坐多久 / 靠背 / 翘腿 / 憋尿 / 咖啡 / 运动后 / 聊天 / 手臂高度 / 左右手 / 袖带隔衣 | 图文步骤卡（1 主图 + 3 步） + 少量手部特写短视频 | 约 50% |
| **② 读数解释**（看得懂） | 一个数就慌，或反复重测 | 第一次数字高要不要重测 / 两次间隔多久 / 一天量几次 / 测量时紧张 | 图文（含"什么情况该联系医生"清单） | 约 30% |
| **③ 记录与就诊**（带得走） | 有记录但复诊用不上 | 记什么、怎么记（时间/姿势/哪只手）、什么时候带、带去问哪三个问题 | 图文模板（可打印/可截图） | 约 20% |

**三支柱的关系与排期建议**：① 让数据成立 → ② 让患者不误判 → ③ 让数据进诊室。建议按这个顺序铺：先做 ①（题池里对应 10 题，最容易被反复问到，也最适合先把版式固定下来），② 穿插补充（4 题），③ 每月一条（题池里仅"什么时候带记录去复诊"1 题，其余需自己拟）。① 是后两步的基础；③ 把前面讲的内容带出家门，适合边做边试，不必等 ① 全部做完才开始。

## 4. 制作节奏（每周 2 小时，可执行版）

**基本盘：每周 2 条图文；每两周加 1 条短视频。**

| 环节 | 时长 | 做法 |
| --- | --- | --- |
| 选题与核对 | 20 min | 从 20 题池按动作链顺序取，不现想；每条只解一个疑问 |
| 写稿 | 40 min | 固定三段：错在哪 → 正确做法（3 步内）→ 什么情况找医生 |
| 出图 / 拍摄 | 45 min | 图文：1 张主图（步骤示意）+ 文字卡；短视频：手机拍手部/袖带特写，配字幕，不出镜讲解 |
| 发布与回评论 | 15 min | 统一边界话术；个案一律引到线下 |

**降低每周成本的两个动作**
- **月初一次定 4 题**（1 小时），之后三周只执行，不在周中做选题决策。
- **一个模板用到底**：同一版式、同一字号（老年可读）、同一结尾"该找医生"清单，只换内容。版式固定后单条制作可压到 40 分钟以内。

**节奏红线**：宁可每周 2 条稳定，不要一周 5 条然后停三周——受众是老年患者，靠的是"每次都能找到同一种东西"。

## 5. 可借鉴 / 不能照搬

### 可以借鉴（有可核验依据）

| 借鉴点 | 依据 |
| --- | --- |
| **标题用患者原话的口语疑问短句，6–10 字** | 20/20 条标题均为疑问短句，无品牌、无数字、无感叹号、无术语 |
| **题池按动作链排**（准备→器具→操作→读数→用药→出口），成系列不散 | 20 题可完整归入该链条 |
| **一条只解一个疑问**，不做"血压全攻略" | 20 题无一题为综述型，全部是单点疑问 |
| **不点品牌、不堆术语** | 原表 20 题零品牌、零专业术语 |

### 不能照搬

| 不能照搬 | 原因 |
| --- | --- |
| 把三账号的点赞/收藏/评论数值当**基准线或排名依据** | 虚构随机数据；同一题跨账号最大差值中位 305、最大 480，单条不可当基准 |
| 用"收藏÷点赞""评论÷点赞"判断**留存能力或争议度** | 只是两个计数的比值，无曝光量，不代表真实留存/争议 |
| 用 30/60/400/800 推**长短内容策略** | 该列字数与秒数混列，且原表无正文，不能推效果 |
| 抄**视觉风格、发布频率、转化路径** | 原表完全没有这三项 → **素材不足**，只能自定（见第 4 节与下文） |
| 照做"正常了能不能停药"的直接答法 | 该题数值最高（462.3），但属用药决策，越界；只做"什么情况必须联系医生"版本 |
| 追热点式选题 | 原表无选题理由记录，选题逻辑属素材不足 |

### 需要自己补的三块（原表给不了）

1. **视觉**：老年可读版式——大字号、高对比、一屏一个动作；封面统一放"步骤序号"，让人一眼知道是系列。
2. **节奏**：见第 4 节（每周 2 图文 / 双周 1 短视频）。
3. **转化**：只设一个出口——**"带记录去复诊"**。不做课程、不做社群、不导流；记录模板就是唯一的"钩子"，它本身就是服务。

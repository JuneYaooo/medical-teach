# 课程导览｜医学科研与患者科普

> 本节是整个课程的第一站：先搞清楚五个核心概念的区别，再用「家庭血压监测」这一个主题，分别走一遍**科研线**和**患者科普线**的学习路线。本节只做导览，不安装任何工具、不发布任何内容。

---

## 一、五个核心概念：一张图分清

| 概念 | 一句话理解 | 类比 | 在医学工作里像什么 |
|---|---|---|---|
| **Agent（智能体）** | 会理解你的意图、拆解任务、自己动手干活的"执行者" | 一位能干的助手 | 一句话让它"帮我整理这批血压数据"，它自己规划步骤并完成 |
| **Skill（技能）** | 预先写好的"专业操作手册"，装上后 Agent 就多了某项专长 | 助手考下的资格证 | 一份"医学科普写作规范"，让输出遵循科普文风和核验流程，仍需测试是否落实 |
| **连接器（Connector）** | 打通外部服务的"接口"，负责授权和数据进出 | 门禁卡 / 网线 | 连接腾讯文档、邮箱等外部服务，把结果同步出去 |
| **工作空间（Workspace）** | 一个项目专用的文件夹 + 记忆区，所有文件和约定都在这里 | 项目专用办公桌 | 本课程的文件夹：素材、录屏、演示输出各归其位 |
| **代码执行** | 在受控环境里真正运行代码，处理数据、算统计量 | 一间设备齐全的实验室 | 用 Python/Pandas 清洗血压记录、算平均值和达标率 |

### 它们怎么配合？

一次典型任务的分工：

1. **你**在工作空间里说："把这周的血压记录整理成图表，再写一段给患者的解释。"
2. **Agent** 接收意图，拆成两步：处理数据 → 写解释文字。
3. 数据处理那步调用**代码执行**，真正跑脚本算数值。
4. 写作那步调用**技能**（比如"患者科普写作"技能）约束文风与核对流程，准确性仍须查证。
5. 如果要把结果存到腾讯文档，就通过**连接器**完成授权和传输。
6. 所有产出文件都留在**工作空间**里，可追溯、可复用。

**记忆口诀**：Agent 是脑子，Skill 是本领，连接器是手脚对外的通道，工作空间是桌子，代码执行是实验室。

## 二、贯穿案例：家庭血压监测

为什么选这个主题？因为它**两头都通**——

- **科研线**看它：是一个真实可做的健康数据采集研究（依从性、测量误差、达标率分析）。
- **患者科普线**看它：是患者最常问的问题（怎么量才准？多少算高？）。

同一段素材，两种用法，正好对比两种工作流的差异。

---

## 三、科研线学习路线

> 目标：从原始记录到可核查的分析结论。

1. **明确研究问题**：例如"老年患者在家自测血压的达标率有多高？测量时间是否影响读数？"
2. **准备模拟数据**：手工或用 AI 生成一份模拟血压记录表（日期、早晚测量值、心率），**全程使用模拟数据练习，不碰任何真实患者信息**。
3. **数据整理**：让 Agent 调用代码执行，清洗缺失值、统一格式、算出周平均和达标率。
4. **结果核对**：抽取几条记录人工验算，确认脚本算得对——AI 产出必须抽查。
5. **来源核验**：涉及医学判断标准（如高血压诊断界值）时，核对权威指南（如《中国高血压防治指南》、国家卫健委发布文件），并在文档中标注出处。
6. **产出**：一份带出处的分析笔记，存入工作空间。

**科研线的关键词**：可复现、可核查、出处明确、模拟数据先行。

---

## 四、患者科普线学习路线

> 目标：把专业知识翻译成老百姓看得懂、信得过的话。

1. **选定患者真问题**：例如"在家量血压，为什么每次数值都不一样？"
2. **收集素材**：整理常见的测量误区（憋尿、袖带位置不对、刚运动完就量等）。
3. **医学事实核验**（科普线最重要的一步）：
   - 每条结论都要能在权威来源里找到依据（指南、卫健委、权威医学科普平台）；
   - 拿不准的宁可删掉，也不编造；AI 给出的说法一律回查来源再采用；
   - 在文档中注明"参考来源"。
4. **通俗化改写**：用生活比喻代替专业术语，但**不牺牲准确性**——比喻不能导致误解（如不能把"偏高"说成"没病"）。
5. **加入行动建议**：给出具体可操作的一句话（"每天固定时间、坐着休息 5 分钟后再量"）。
6. **产出**：一篇短科普文，存入工作空间，供后续排版使用。

**科普线的关键词**：通俗不失真、每条有出处、给出可行动建议。

---

## 五、两条线的对比

| 维度 | 科研线 | 患者科普线 |
|---|---|---|
| 核心产出 | 数据分析结论 | 通俗短文 |
| 数据 | 模拟数据集 | 事实清单 |
| 核验重点 | 统计正确 + 指南出处 | 每句话有医学依据 |
| 主要工具 | 代码执行 + Agent | Skill（写作规范）+ Agent |
| 读者 | 自己 / 研究同行 | 普通患者 |

---

## 六、医学内容的两条铁律（贯穿全课程）

1. **来源核验优先**：AI 生成的一切医学表述都是"待核实的草稿"。诊断标准、用药建议、数值界限，必须回查权威指南或官方文件，并在文档中写明出处。AI 可能出错，核验不能省。
2. **只用模拟数据**：课程所有练习一律使用模拟数据，绝不录入真实患者的姓名、病历号等个人信息。等流程熟练后，如何合规处理真实数据属于另外的专门课题。

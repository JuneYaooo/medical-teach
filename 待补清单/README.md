### 7. 补中国指南事实卡（需医生审定）
- 位置：`WorkBuddy教程/资料/家庭血压事实卡.csv`，以及引用它的科普成果。
- 背景：现在 F01–F10 只来自 AHA 患者教育页面。选题库里 Q05、Q10、Q13、Q17、Q18、Q22 因此一直是“待核验”。
- 要做：依据《中国家庭血压监测指南（2019）》《中国高血压防治指南》起草新卡，每张写清原文位置，审核状态填“未审核”。
  - 家庭血压诊断阈值 ≥135/85 mmHg。
  - 早晚测量时间：早晨起床 1 小时内、服药和早餐前、排尿后；晚上睡前。
  - 诊断或调药期间连续测 7 天（至少 3 天），算平均值时去掉第 1 天。
  - 首诊双臂都测，以后测读数较高的一侧；双臂差值 >20 mmHg 时就医。
  - 选用经过验证的上臂式电子血压计。
- F07 补“背部有支撑、双脚平放、不跷腿”；补一张“房颤或心律不齐时电子血压计可能不准”的卡。
- 补一张急症就医卡：读数 >180/120 mmHg，或伴胸痛、气短、意识混乱、说话困难等症状时如何处理（AHA 页面有对应内容）。

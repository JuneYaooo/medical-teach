# 医学工作流课堂

用 WorkBuddy 练习医学科研与患者科普：从资料和提示词出发，打开结果文件，再核对数字、来源与表述。

**[进入课程网站](https://juneyaooo.github.io/medical-teach/)**

- 入门：工作空间、技能与证据核对。
- 科研线：文献检索、方案与 SAP、数据清洗、统计、论文与审稿回复、基金申请、项目协作。
- 科普线：选题、事实卡、文章、分镜、图文海报、口播预览、患教材料与内容技能。

19 节课程均提供 Markdown 正文、配套文件与实际操作画面；录屏包含中文讲解、硬字幕、可选字幕轨道和章节定位。

## 使用

1. 安装 WorkBuddy（课程按 5.9.0 录制）。
2. 在网站首页下载练习包 `WorkBuddy教程-练习包.zip` 并解压，得到 `家庭血压项目` 文件夹（含资料、空的成果文件夹和参考结果）。
3. 在 WorkBuddy 新建任务时把这个文件夹选为工作空间，然后从 01 入门课开始，再选科研线或科普线。

每课开头有时长、难度、前置课程和实操录屏；可以标记“已学完”，首页会显示进度和“继续学习”（进度只保存在当前浏览器）。

也可以下载仓库后，在本地打开 `index.html`。视频与截图均使用相对链接。

## 内容范围

研究数据、审稿意见和项目资料为教学模拟，不代表临床研究证据。医学事实卡附来源，来源核对不等于医生签署。P6 提供本次口播稿生成的数字人成片、字幕与配音文件。

## 编辑课程

课程源稿位于 `WorkBuddy教程/课程/*.md`。修改后重新生成静态网页：

```sh
python3 -m pip install -r requirements.txt
python3 scripts/build_site.py
```

构建脚本同时会重新生成练习包（`资料/` + `成果/` 中小于 2MB 的文件作为参考结果）。网站无需数据库。样式和交互脚本位于 `WorkBuddy教程/assets`。

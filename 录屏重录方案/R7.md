# R7 项目管理与会议纪要 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/R7-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 30 秒 – 3 分 15 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/虚构组会转写.txt` |
| 这一段要教会 | ① 从会议转写整理待办时，负责人和截止日期只能按原话填；② 发现 AI 把“提出问题的人”填成负责人、把“全体”当负责人，让它改成“待确认”；③ 每处修改留下依据和时间点；④ 进度表有状态下拉和逾期高亮 |

旧录屏的问题：35 秒只有一个章节“查看修订后进度表与周报”——没有输入、没有错误、没有修改过程；复盘里的关键错误（提出问题的人被填成负责人）完全看不到；Excel 太小，状态下拉和高亮看不清。

转写里的关键原话（用于核对）：

- `02:10 陈研究员：数据里有三条重复记录，得先对比所有字段，完全一致才能去掉。`（只是提出问题，没说谁做）
- `06:30 陈研究员：我负责分析脚本，11月3日前提交可重复版本。`（明确认领）
- `10:00 林医生：伦理材料还缺风险说明，这个谁负责还没定，先列待确认。`
- `12:00 周协调员：设备核验计划也没定截止日期。`
- `14:00 林医生：11月5日开下次会。`（没说谁组织）

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/R7"
mkdir -p 录屏重录方案/_work/R7/raw
python3 -c "import openpyxl" 2>/dev/null || python3 -m pip install --user openpyxl   # C 分支检查要用
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 看转写（原始片段 `R7-S1.mp4`）

1. 开始录制。
2. 在 Finder 打开 `~/WorkBuddy录制/WorkBuddy教程/实操素材/虚构组会转写.txt`，用“文本编辑”打开，窗口 1440×900，字号调到 18 以上。
3. 停在全文 4 秒（转写很短，一屏能放下）。**标记 M1-1**。
4. 鼠标移到 `02:10` 那一行停 3 秒。**标记 M1-2**。
5. 鼠标移到 `06:30` 那一行停 3 秒。**标记 M1-3**。
6. 关闭窗口，结束录制。

### S2 整理纪要（原始片段 `R7-S2.mp4`）

1. 开始录制。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
读取实操素材/虚构组会转写.txt，整理会议决议、待办、遗留问题。只以转写为依据。伦理风险说明缺负责人、设备核验计划缺日期，不得补造；分别列待确认。
```

4. 停 3 秒。**标记 M2-1**。
5. 发送，等待生成完成。**标记 M2-2**。
6. 结束录制。

### S3 生成进度表（原始片段 `R7-S3.mp4`）

1. 开始录制。
2. 点击同一任务的输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
将明确待办生成进度表Excel和一页周报，列任务编号、任务、负责人、截止日期、状态、前置任务、来源时间点。状态下拉和逾期未完成条件格式。已有文件则按任务编号更新并生成变更清单，避免重复新增。输出到演示输出/R7/；不要创建线上日程或给人发送消息。
```

3. 停 3 秒。**标记 M3-1**。
4. 发送，等待完成。回复里出现 `R7项目进度表.xlsx` 和 `R7周报.html` 文件卡片时 **标记 M3-2**。
5. 点击 `R7项目进度表.xlsx` 文件卡片，右侧用 WorkBuddy 自带的表格预览打开。点预览区右上角的放大按钮，让表格铺满窗口。停 3 秒。**标记 M3-3**。
6. 鼠标移到 T1 行的“负责人”单元格，停 4 秒。**标记 M3-4**。
7. 鼠标移到 T6 行的“负责人”单元格，停 3 秒。**标记 M3-5**。
8. 点预览区右上角的缩小按钮还原。结束录制。

**此时按“C. 分支”判断走主线还是分支 B。**

### S4 人工复核纠正（仅主线，原始片段 `R7-S4.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（上次实操实际输入的原文）：

```text
逐项复核发现：02:10陈研究员只是提出重复记录问题，没有明确承担核查；T1负责人改为待确认，不能由发言者推断负责人。T6“全体”是可能参会者，不是组织负责人，也保留待确认。T5负责人也没给。状态与缺项一致；保留原来源。逾期条件应为有效日期、日期早于今天且状态不等于已完成，不要因为待确认就掩盖逾期。补一列/单独待确认说明明确每条缺什么；保存修改清单与Markdown会议纪要，同步更新原xlsx和周报HTML。
```

3. 停 3 秒。**标记 M4-1**。
4. 发送，等待完成。
5. 点击更新后的 `R7项目进度表.xlsx` 文件卡片，放大铺满。停 3 秒。**标记 M4-2**。
6. 鼠标移到 T1 行“负责人”（应为“待确认”）停 3 秒。**标记 M4-3**。
7. 鼠标移到“待确认说明”那一列表头，再移到 T1 那一格，停 4 秒。**标记 M4-4**。
8. 点击 T2 行“状态”单元格，点开它的下拉箭头，停 3 秒，按 Esc 关闭（**不要改值**）。**标记 M4-5**。
9. 还原预览区。点击 `R7变更清单.md` 文件卡片，停在“按任务编号的变更明细”表的 T1 那几行 4 秒。**标记 M4-6**。
10. 结束录制。

### S5 看周报（原始片段 `R7-S5.mp4`）

1. 开始录制。
2. 点击 `R7周报.html` 文件卡片，停在顶部 3 秒。**标记 M5-1**。
3. 滚动到“待确认事项”区块，停 4 秒。**标记 M5-2**。
4. 结束录制。

## C. 分支

S3 结束后，检查进度表：

```sh
python3 - <<'EOF'
import openpyxl, os
p = os.path.expanduser("~/WorkBuddy录制/WorkBuddy教程/演示输出/R7/R7项目进度表.xlsx")
ws = openpyxl.load_workbook(p).active
head = [c.value for c in ws[1]]
i = next(k for k, h in enumerate(head) if h and "负责人" in str(h))
for r in ws.iter_rows(min_row=2, values_only=True):
    if r[0]: print(r[0], "负责人=", r[i])
EOF
```

- T1 负责人是“陈研究员”，或 T6 负责人是“全体”，或 T4 / T5 负责人是空白（不是“待确认”）→ **主线**，录 S4。
- T1、T4、T5、T6 的负责人都已经是“待确认”→ **分支 B**，跳过 S4，镜头 7–10 换成分支 B 镜头。另外单独录一段 `R7-S4b.mp4`：放大进度表，依次把鼠标停在 T1 负责人、T2 状态下拉（点开再 Esc）上，标记 M4b-1、M4b-2；再打开周报“待确认事项”。
- 任务编号和行顺序与上面不同（例如编号叫 A1…）时，按任务内容对应：T1 = 重复记录核查，T4 = 伦理风险说明，T5 = 设备核验计划，T6 = 下次组会。

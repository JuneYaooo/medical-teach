# P6 数字人口播 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P6-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 00 秒 – 3 分 40 秒 |
| 前置产物 | 无（参考样片从仓库复制，见 A） |
| 用到的素材 | `实操素材/教学事实卡.csv`；仓库里的 `WorkBuddy教程/演示输出/P6/P6-形象口型检查参考.mp4`（已授权的既有数字人形象样片） |
| 这一段要教会 | ① 口播稿要分“给人看的标注版”和“给机器念的纯文本版”；② 先试听术语读音；③ 发布前逐项判断授权、审核、标识、音画同步；没看过成片不写“通过”；④ 参考样片不是本课成片 |

旧录屏的问题：后 41 秒都在播一段数字人样片，它的台词和本课新稿不是同一份，没有讲解时会被当成本课成片；录制中弹出 macOS 权限弹窗；结尾混入无关会话；口播稿和发布前判断表几乎没出现。

**关于试听音频的来源**：课程源稿的两段提示词都没有要求生成试听音频。旧录屏时是另加了一段要求，让 WorkBuddy 用本机 macOS `say` 合成试听（见截图 `P6-口播试听任务.png`）。本规格把它单独作为 S4 追加指令，原文照截图逐字使用。预览页 `P6-预览检查.html`（左边样片、右边试听）同样用 S4 一并生成。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
REPO=/Users/june2/code/github/medical-teach
rm -rf "$WS/演示输出/P6"
mkdir -p "$WS/演示输出/P6"
# 参考样片不在练习包里，从仓库复制（只复制样片，其他文件要当场生成）
cp "$REPO/WorkBuddy教程/演示输出/P6/P6-形象口型检查参考.mp4" "$WS/演示输出/P6/"
mkdir -p 录屏重录方案/_work/P6/raw
```

在 WorkBuddy 里：关闭右侧所有标签页；左侧任务列表清空或收起；确认统一模型。

**系统权限**：S4 会调用 `say` 和音频转换，可能触发“WorkBuddy 想要访问……”的系统弹窗。录制前先在一个不录制的临时任务里执行一次下面的指令，把弹窗全部点“允许”，然后删掉这个临时任务、删掉它生成的文件：

```text
当前工作空间：WorkBuddy教程。
用本机 say 命令合成一句“测试”，保存为演示输出/P6/_权限测试.m4a，然后删除这个文件。
```

```sh
rm -f "$WS/演示输出/P6/_权限测试.m4a"
```

## B. 录制步骤

### S1 写口播稿（原始片段 `P6-S1.mp4`）

1. 开始录制。点左上角“新建任务”，确认输入框下方显示 `WorkBuddy教程`。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
基于实操素材/教学事实卡.csv写60–90秒教学数字人口播稿，标注停顿、术语读法和每句F编号；另输出用于TTS的纯文本稿，不把F编号和停顿符号念出来。检查毫米汞柱和量血压的读法。
```

3. 停 3 秒。**标记 M1-1**。
4. 发送，等待完成（README 4.3）。生成完成、回复里出现文件卡片时 **标记 M1-2**。
5. 结束录制。

### S2 看两份稿（原始片段 `P6-S2.mp4`）

1. 开始录制。
2. 点击“带标注”口播稿的文件卡片（文件名类似 `P6-口播稿-带标注.md`；没有卡片就点“查看所有产物”找）。右侧预览打开，停在表格开头 3 秒。**标记 M2-1**。
3. 慢慢滚到含“毫米汞柱”或“F09”的那几行，停 4 秒。**标记 M2-2**。
4. 点击纯文本稿文件卡片（类似 `P6-TTS纯文本稿.txt`），停 4 秒。**标记 M2-3**。
5. 结束录制。

### S3 发布前判断表（原始片段 `P6-S3.mp4`）

1. 开始录制。点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
生成数字人预览制作参数表、字幕稿、发布前判断表。肖像授权、医生审核、标识、音画同步和术语读音逐项保持真实状态；未看成片不得写通过。不要调用付费API，不要上传新肖像或声音，不发布；输出到演示输出/P6/。
```

2. 停 3 秒。**标记 M3-1**。
3. 发送，等待完成。**标记 M3-2**（完成时）。
4. 点击发布前判断表文件卡片（类似 `P6-发布前判断表.md`），停在表格顶部 4 秒。**标记 M3-3**。
5. 慢慢向下滚到“总体结论”，停 4 秒。**标记 M3-4**。
6. 结束录制。

### S4 生成读音试听和预览页（原始片段 `P6-S4.mp4`）

1. 开始录制。点击输入框，粘贴（前半段为旧录屏实际使用的原文）：

```text
当前工作空间：WorkBuddy教程。
再使用本机已安装的macOS中文say声音生成一段15–25秒读音试听，包含“量血压”“毫米汞柱”“间隔一分钟”，转成可播放音频，检查实际时长；这是本地合成语音，不能冒充本人克隆声。不要安装新声音或调用付费服务。音频未听则写待试听，数字人口型未看则写待检查。
再做一个本地预览页演示输出/P6/P6-预览检查.html：左边放已有的P6-形象口型检查参考.mp4，注明“已有形象样片，台词与本课新稿不同”；右边放刚生成的试听音频。
```

2. 停 3 秒。**标记 M4-1**。
3. 发送，等待完成。**标记 M4-2**。
4. 点击 `P6-预览检查.html` 文件卡片，右侧预览打开。停在页面顶部 3 秒。**标记 M4-3**。
5. 点击左侧样片的播放按钮，播放 5 秒后点暂停。**标记 M4-4**（开始播放的时刻）。
6. 点击右侧试听音频的播放按钮，让它完整播放（约 23 秒），期间不动鼠标。**标记 M4-5**（开始播放的时刻）。
7. 结束录制。

> 录屏不录声音。试听音频在剪辑时直接混入，见镜头 9。

## C. 分支

S3 结束后读 `$WS/演示输出/P6/` 下文件名含“发布前判断”的 .md 文件：

- 每一项的判定都**不含**“通过”二字（“不通过”“待试听”“待成片检查”可以），总体结论含“不可发布”或“暂不发布” → **主线**。
- 任何一项写了“通过”（不是“不通过”）而又没有看过成片，或总体结论写“可以发布” → **分支 B**：录一段纠正。新建原始片段 `P6-S3b.mp4`，在输入框粘贴下面的文字，发送，等完成后重新打开判断表停 4 秒（**标记 M3b-1**）：

```text
发布前判断表里有项目写了“通过”，但成片还没有合成、也没有人看过。请把没有实际看过、听过的项目全部改为“待检查”或“不通过”，总体结论写“当前不可发布”，并说明原因。更新同一个文件。
```

分支 B 时，剪辑表镜头 8 之后插入镜头 8B。

S4 结束后检查：`$WS/演示输出/P6/` 下是否有 .m4a 或 .wav 试听文件。没有（例如 `say` 被拒绝）→ 在 report.md 记录，剪辑时去掉镜头 9，改用镜头 9B。

## F. 验收

- [ ] “参考样片 · 非本课成片”大字在样片出现的全程可见；样片画面不超过 10 秒。
- [ ] 试听音频能在成片里听到，旁白没有盖住它。
- [ ] 发布前判断表每一项都被念到，并看到“不可发布”的结论。
- [ ] 两份稿（标注版 / 纯文本版）并排出现过。
- [ ] 全程没有系统权限弹窗、无关会话。
- [ ] 时长在 3:00–3:40 之间。

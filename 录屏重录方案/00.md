## A. 录前重置

```sh
REPO=/Users/june2/code/github/medical-teach
cd "$REPO" && python3 scripts/build_site.py      # 确保网站是最新文案
# 解压一份全新的练习包，专门给本段展示用（录制工作区里已经堆满了各课结果，不能用）
rm -rf ~/WorkBuddy录制/展示用 && mkdir -p ~/WorkBuddy录制/展示用
cd ~/WorkBuddy录制/展示用 && unzip -q "$REPO/WorkBuddy教程/WorkBuddy教程-练习包.zip"
mkdir -p "$REPO/录屏重录方案/_work/00/raw"
```

浏览器（建议 Chrome）：

```sh
open -na "Google Chrome" --args --incognito --window-size=1440,900 --window-position=0,25 \
  "file:///Users/june2/code/github/medical-teach/index.html"
```

- 使用**无痕窗口**，这样学习进度（浏览器本地存储 `medical-teach:progress:v1`）是空的，首页不会出现“继续学习”。
- 不显示书签栏；只开这一个标签页。
- 浏览器缩放保持 100%；如果字太小，可以调到 110%，整段保持一致。

Finder：新开一个窗口，1440×900，列表视图，打开 `~/WorkBuddy录制/展示用/WorkBuddy教程`，先最小化。

## B. 录制步骤

下面的按钮文字来自 `scripts/build_site.py`。如果录制时网站文案已按 README 第十节改过（例如“1 分钟录屏”改成了“讲解录屏”），按画面上实际文字操作，并在 report.md 记录。

### S1 首页：两条路线（原始片段 `00-S1.mp4`）

1. 开始录制。停在首页顶部 3 秒（能看到大标题“让医学工作流可复现、可核对。”和“开始入门课 →”“下载练习包”两个按钮）。**标记 M1-1**。
2. 鼠标慢慢移到右侧“开始前准备”框，停 4 秒。**标记 M1-2**。
3. 慢慢向下滚动到“第一步 · 先学入门课”区块，停 3 秒（能看到 01 和 00 两张卡片）。**标记 M1-3**。
4. 继续向下滚到“第二步 · 选一条路线”，停 2 秒；再滚到“医学科研线”标题停 3 秒（**标记 M1-4**），再滚到“患者科普线”标题和下面的建议顺序提示停 4 秒（**标记 M1-5**）。
5. 结束录制。

### S2 练习包（原始片段 `00-S2.mp4`）

1. 开始录制。滚回首页顶部，鼠标移到“下载练习包”按钮上停 3 秒（**不点击**，避免出现下载栏）。**标记 M2-1**。
2. 切到 Finder 窗口（已打开 `~/WorkBuddy录制/展示用/WorkBuddy教程`），停 3 秒，能看到 `实操素材`、`演示输出`、`参考结果`、`开始前请读.txt`。**标记 M2-2**。
3. 依次选中 `实操素材`、`演示输出`、`参考结果`（单击选中即可，不展开），各停 2 秒。分别 **标记 M2-3、M2-4、M2-5**。
4. 结束录制。

### S3 一课里有什么（原始片段 `00-S3.mp4`）

以 R1 为例。

1. 开始录制，切回浏览器。滚到“医学科研线”，点击 **R1 文献情报与选题** 卡片。
2. 课程页打开后停在顶部 3 秒，能看到“时长 / 难度 / 前置 / 产出”和“怎么学”。**标记 M3-1**。
3. 向下滚到“实操录屏”区块，停 3 秒（能看到视频和下面的章节按钮）。**标记 M3-2**。
4. 向下滚到“快速实操”里第一个提示词代码块，鼠标移到右上角“复制”按钮上停 3 秒（可以点一下，按钮会变成“已复制”）。**标记 M3-3**。
5. 向下滚到“本次实操复盘”段落，停 4 秒。**标记 M3-4**。
6. 向下滚到“配套结果文件”，停 3 秒。**标记 M3-5**。
7. 结束录制。

### S4 标记学完（原始片段 `00-S4.mp4`）

1. 开始录制。在 R1 课程页滚到“标记本课已学完”按钮，点击，按钮变成“✓ 已学完（点击取消）”，停 3 秒。**标记 M4-1**。
2. 点页面左上角站点名回到首页（或浏览器后退）。首页顶部出现“继续学习：……”提示，科研线右侧显示“已学完 1 / 8”，停 4 秒。**标记 M4-2**。
3. 结束录制。

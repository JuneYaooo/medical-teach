# 录屏与剪辑实践手册

本手册把本项目现有录屏规格里的 macOS/FFmpeg 录屏命令、MiniMax 配音命令，与 01 入门录屏确认通过的构图和字幕样式合在一起。每课仍先按对应的 `00.md`、`01.md`、`R1.md`…或 `P1.md`…执行具体操作；本手册说明如何录、如何剪、如何检查。

## 1. 文件和工具

建议每课使用独立的工作目录，原始录屏、配音、中间片段和检查帧放在 `_work` 下；最终 MP4、章节 JSON、VTT 放在 `WorkBuddy教程/录屏/`。

```sh
cd /path/to/medical-teach

REPO="$PWD"
COURSE="01"
WORK="$REPO/录屏重录方案/_work/$COURSE"
RAW="$WORK/raw"
VOICE="$WORK/voice"
CAPTIONS="$WORK/captions"
DRAFT="$WORK/draft"
CHECK="$WORK/check"

mkdir -p "$RAW" "$VOICE" "$CAPTIONS" "$DRAFT" "$CHECK"

FFMPEG="$(command -v ffmpeg)"
FFPROBE="$(command -v ffprobe)"
```

如果 `command -v` 没有找到程序，先安装或定位本机已有的 FFmpeg，再把 `FFMPEG`、`FFPROBE` 设为实际路径。不要把访问密钥写入仓库。

每课开始前先读对应分镜文件，核实 WorkBuddy 版本、模型、工作空间、素材和输出目录。原始录屏只录屏幕和鼠标，不录系统声音；旁白单独生成，便于按镜头剪辑和调整语速。

## 2. 屏幕录制

### 2.1 准备画面

1. 按课程规格重置本课的 WorkBuddy 任务和输出目录，确保显示的是本次操作结果。
2. 收起无关任务与侧栏，关闭其他课程的预览和标签页；提前设置勿扰，避免通知或权限弹窗打断录制。
3. WorkBuddy 和表格等主要窗口尽量使用统一尺寸。先确认屏幕录制分辨率；Retina 屏幕可能输出 2 倍像素，不能直接照搬窗口坐标。
4. 输入长提示词时使用剪贴板粘贴。鼠标移动保持简洁；关键结果出现后停留片刻，留出后期选取画面的时间。

### 2.2 用 FFmpeg 录制

先查看 macOS 屏幕设备编号：

```sh
"$FFMPEG" -f avfoundation -list_devices true -i "" 2>&1 | grep -i "capture screen"
```

把下面的 `SCREEN_ID` 换成输出中的主屏幕编号。执行后按 `q` 结束录制：

```sh
SCREEN_ID="1"
"$FFMPEG" -f avfoundation \
  -capture_cursor 1 -capture_mouse_clicks 1 -framerate 30 \
  -i "$SCREEN_ID:none" \
  -c:v libx264 -preset ultrafast -crf 18 -pix_fmt yuv420p \
  "$RAW/${COURSE}-S1.mp4"
```

每个主要操作步骤分别录成 `S1`、`S2` 等片段。关键操作发生时记下相对秒数，写到 `$WORK/marks.json`，例如：

```json
{
  "S1": { "M1-1": 3.2, "M1-2": 8.9 },
  "S2": { "M2-1": 1.5 }
}
```

录完先检查源视频属性和画面：

```sh
"$FFPROBE" -v error \
  -show_entries stream=codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=1 "$RAW/${COURSE}-S1.mp4"

"$FFMPEG" -y -ss 5 -i "$RAW/${COURSE}-S1.mp4" -frames:v 1 "$CHECK/S1-05.png"
```

如果画面里出现通知、权限弹窗、无关任务或录错的操作，先补录对应步骤，再进入剪辑。

## 3. 旁白和字幕

### 3.1 MiniMax 旁白

旁白以课程规格中的逐字稿为准。为 TTS 制作朗读稿时只替换读音，不改字幕原文。使用 capsule-cinema 现有的 MiniMax 配置：`speech-2.8-turbo`、`male-qn-jingying`；凭据由本机配置读取。

项目原有的 `UniversalTTSTool` 调用方式：

```sh
export CAPSULE_CINEMA="/path/to/capsule-cinema"
cd "$VOICE"

python "$CAPSULE_CINEMA/scripts/run_tool.py" --tool UniversalTTSTool \
  --params '{"text":"朗读稿","provider":"minimax","voice_type":"male-qn-jingying","speed":1.08,"allow_provider_fallback":false,"allow_local_fallback":false,"output_path":"shot.mp3"}'
```

生成后听完每个镜头。只有语速确实偏慢时才做无变调加速，并听一遍确认发音和停顿没有变得生硬。本次 01 样片采用 TTS `speed=1.08`，之后用 `atempo=1.18` 加速：

```sh
"$FFMPEG" -y -i "$VOICE/01.mp3" \
  -filter:a "atempo=1.18" -q:a 3 "$VOICE/01-fast.mp3"
```

用处理后的声音重新测时。镜头通常跟随实际旁白长度结束，不默认附加静音尾巴；分镜要求展示确认动作时，才按需要延长或定格。原始画面短于旁白时，用最后一帧补齐；只加速等待，不加速正常操作。

### 3.2 字幕

- 字幕文字来自原始旁白逐字稿；TTS 读音替换只用于声音，字幕保留正常拼写。
- 按语义和标点分句，每条最多两行，每行约 22 个汉字以内；时间按该句字符数和镜头配音长度分配，再人工核对停顿。
- 成片烧录硬字幕，同时输出同内容的 `.vtt`。
- 本项目当前样式：放在画面底部居中区域，深墨色 PingFang 字，约 38px、常规字重，浅色描边；不加厚重黑底条。保持对比清楚，并避免压住操作界面。

## 4. 画面构图和剪辑

### 4.1 默认构图：完整界面 + 同步细节

每个镜头都让观众知道当前在哪个应用、正在做什么。默认使用 1920×1080 画布：

- 背景为暖白 `#F7F6F0`，标题用深墨色 `#1F3030`，重点标记用青绿色 `#2E7D6B`。
- 左侧持续显示完整应用界面缩略图，约 600×338，作为全局上下文。
- 右侧显示与左侧同一时刻的操作细节，约 1110×624；需要聚焦时，在细节图中用青绿色细框标出当前区域。
- 顶部写课程/步骤标题和本镜头动作，例如“步骤 1｜选择工作空间”；两幅画面上方分别标注“完整界面”和“操作细节”。
- 开场先用约 2 秒标题卡交代课程，再进入操作画面。标题卡和操作画面使用一致的暖白、深墨色和青绿色。

构图中的坐标和尺寸（1920×1080 成片坐标）：

| 元素 | 位置与尺寸 |
| --- | --- |
| 全局画面 | x=80, y=280, 600×338 |
| 同步细节 | x=732, y=280, 1110×624 |
| 主标题区域 | 左上，约 y=60–160 |
| 字幕区域 | 底部居中，留在画布浅色底带内 |

用 Pillow 生成 `layout.png`：暖白底、标题、步骤标签、两张卡片留白。以下片段按本次样片的字体文件和布局参数写成；系统更新后如果字体资产路径变化，替换为本机可用的 PingFang 字体路径。

### 4.2 FFmpeg 双画面合成模板

`layout.png` 是一张 1920×1080 的暖白画布，预先画好标题、步骤标签和两张面板边框。`CROP_X`、`CROP_Y` 应从检查帧中确定，裁剪框必须在源画面范围内。

```sh
LAYOUT="$WORK/layout-01.png"
SOURCE="$RAW/01-S1.mp4"
NARRATION="$VOICE/01-fast.mp3"
CAPTION="$CAPTIONS/01.ass"
CROP_X="400"
CROP_Y="160"
DURATION="7.57"

"$FFMPEG" -y -i "$SOURCE" -i "$NARRATION" \
  -loop 1 -framerate 30 -i "$LAYOUT" \
  -filter_complex "[0:v]split=2[full][zoom];\
[full]scale=600:338:force_original_aspect_ratio=decrease,\
pad=600:338:(ow-iw)/2:(oh-ih)/2:color=0xF7F6F0,setsar=1[context];\
[zoom]crop=1100:620:${CROP_X}:${CROP_Y},scale=1110:624:flags=lanczos,setsar=1[detail];\
[2:v][context]overlay=80:280[stage];\
[stage][detail]overlay=732:280,fps=30,ass=${CAPTION}[v]" \
  -map "[v]" -map 1:a:0 -t "$DURATION" \
  -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -ar 48000 -movflags +faststart \
  "$DRAFT/01.mp4"
```

需要从同一原始录屏取多个不连续片段时，先分别对全局画面和细节画面执行相同的 `trim`，再分别 `concat`，以保证两路画面同步。重点位置可以用 `drawbox` 标记；长文镜头如果不能完整显示目标句子，就缩小细节裁剪范围或直接展示完整窗口，不要截掉句子后半截。

## 5. 拼接和导出

各镜头分别完成画面、配音和硬字幕后，写一个顺序清楚的 `concat.txt`：

```text
file '/绝对路径/01.mp4'
file '/绝对路径/02.mp4'
file '/绝对路径/03.mp4'
```

所有镜头保持一致的画幅、帧率和编码参数，再拼成整课：

```sh
"$FFMPEG" -y -f concat -safe 0 -i "$DRAFT/concat.txt" \
  -vf fps=30 -r 30 \
  -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -ar 48000 -movflags +faststart \
  "$DRAFT/${COURSE}-WorkBuddy实操.mp4"
```

最终交付 MP4、章节 `.json`、字幕 `.vtt` 到 `WorkBuddy教程/录屏/`。章节起止时间按配音处理后的成片重新计算，不沿用录制前估算值。

## 6. 成片检查

```sh
"$FFPROBE" -v error \
  -show_entries format=duration,size -show_entries stream=codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=1 "$DRAFT/${COURSE}-WorkBuddy实操.mp4"

"$FFMPEG" -y -ss 30 -i "$DRAFT/${COURSE}-WorkBuddy实操.mp4" \
  -frames:v 1 "$CHECK/frame-30.png"
```

逐段抽查开头、操作中段和结果画面，并从头听完整旁白：

- 左侧始终能辨认当前完整应用与页面，右侧细节和左侧时间同步。
- 步骤标题能说明当前操作；画面没有无关任务、通知或权限弹窗。
- 放大区域包含完整关键词、句子或表格列，不裁断行尾。
- 字幕断句自然、时长匹配旁白，文字没有压住关键操作。
- 旁白没有读错数字、英文缩写或专有名词；语速清楚，结尾没有多余静音。
- MP4 有视频和音频流，1920×1080、30fps；JSON、VTT 与最终时长对应。

每课记录原始录制日期、WorkBuddy 版本/模型、实际走过的分支、语音参数、主要剪辑决定和检查结果，写到该课 `_work/<课号>/report.md`。

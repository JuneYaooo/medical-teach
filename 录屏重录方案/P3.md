# P3 科普长文与事实卡 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P3-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 00 秒 – 3 分 40 秒 |
| 前置产物 | 01 课已安装 `medical-evidence-check` 技能（没装就按 01.md S3 先装好，不录） |
| 用到的素材 | `实操素材/教学事实卡.csv`（F01–F10）、`实操素材/来源索引.md` |
| 这一段要教会 | ① 事实卡是什么：每条医学事实有编号、来源、限定，以及“医生签署”状态；② 文章里每句医学信息都要带 F 编号，并能对回事实卡；③ 故意塞一句错话，看逐句核验能不能把它拦下；④ 本地预览≠已发公众号，来源核对≠医生签署 |

旧录屏的问题：36 秒只有“输入”和“预览文章”两段；本课重点“错误注入测试”和“逐句反向核验”都没录到；看不出 F 编号和事实卡怎么对应。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P3"
mkdir -p 录屏重录方案/_work/P3/raw
```

在 WorkBuddy 里：确认“专家·技能·连接器 → 技能 → 已安装”里 `medical-evidence-check` 开关为开启；关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 看事实卡（原始片段 `P3-S1.mp4`）

1. 在 Finder 里选中 `~/WorkBuddy录制/WorkBuddy教程/实操素材/教学事实卡.csv`，右键 → 打开方式 → Numbers（没有就用 Excel），窗口 1440×900。把“事实陈述”列拉宽到能看全文字。
2. 开始录制。停在表格顶部 3 秒，能看到列名“编号、事实陈述、来源、来源位置、适用与限定、核对状态、医生签署、核对日期”。**标记 M1-1**。
3. 鼠标移到 F05 行（“测量前排空膀胱并安静休息至少5分钟。”），停 3 秒。**标记 M1-2**。
4. 鼠标移到“医生签署”列的任意单元格（值为“未签署”），停 3 秒。**标记 M1-3**。
5. 结束录制，关闭表格（不保存）。

### S2 用事实卡写文章（原始片段 `P3-S2.mp4`）

1. 开始录制，画面在 WorkBuddy 首页。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 选择（剪辑时去掉）。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
使用medical-evidence-check技能检查实操素材/教学事实卡.csv的来源、限定条件、日期和医生签署。事实卡只有教学来源核对，没有医生签署；可以生成明确标为教学草稿的内容，不能写临床已审核。以家庭量血压前的准备为主题，用事实卡写800–1200字教学文章，每句医学信息带F编号，不为凑字数添加事实。
```

4. 停 3 秒。**标记 M2-1**。
5. 发送。回复里出现读取 / 使用 `medical-evidence-check` 技能的提示时，**标记 M2-2**。
6. 等待生成完成。回复里出现文章文件卡片（.md）时 **标记 M2-3**；如果文章只在对话里没有存文件，就在左栏滚到文章正文开头时标记。
7. 结束录制。

### S3 对回事实卡（原始片段 `P3-S3.mp4`）

1. 开始录制。
2. 点击文章文件卡片，右侧预览打开（没有文件就看左栏）。停在标题和开头 3 秒。**标记 M3-1**。
3. 慢慢向下滚，找到带 `F05` 的句子（“排空膀胱……休息至少 5 分钟”），停 4 秒。**标记 M3-2**。
4. 结束录制。

### S4 逐句反向核验 + 错误注入测试（原始片段 `P3-S4.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（最后一行是旧录制时实际追加的要求，保留）：

```text
当前工作空间：WorkBuddy教程。
对文章逐句反向核验。另将“只要量得准就能治愈高血压”作为故意错误测试句，判定其无对应，展示删除的前后对照；它不能进入正式草稿。保存带编号文章、核验表、可预览HTML到演示输出/P3/。保留医生签署未完成状态，不登录公众号或发送草稿。
每条编号必须支持句子的完整含义，不只是末尾随便加编号；无法支撑则收窄或删除。
```

3. 停 3 秒。**标记 M4-1**。
4. 发送，等待生成完成。回复里出现核验表、文章、HTML 三个文件卡片时 **标记 M4-2**。
5. 结束录制。

### S5 看核验表（原始片段 `P3-S5.mp4`）

1. 开始录制。
2. 点击核验表文件卡片（文件名含“核验”）。停在逐句核验表开头 3 秒。**标记 M5-1**。
3. 滚动到“故意错误测试句”部分，停在显示“只要量得准就能治愈高血压”和“无对应 / 不支持”的地方 5 秒。**标记 M5-2**。
4. 继续滚到“删除前后对照”，停 5 秒。**标记 M5-3**。
5. 如果核验表里有某句被判为“收窄”或“删除”（不是测试句），滚过去停 4 秒，**标记 M5-4**；没有就跳过。
6. 结束录制。

### S6 看 HTML 预览（原始片段 `P3-S6.mp4`）

1. 开始录制。
2. 点击 .html 文件卡片，右侧预览打开（可点预览区右上角放大图标铺满窗口）。停在顶部的“教学草稿 / 医生签署：未完成”提示框 4 秒。**标记 M6-1**。
3. 向下滚到“测量前 30 分钟”或“排空与静坐”那一节，停 4 秒，能看到句末的 `S… | F…` 编号标签。**标记 M6-2**。
4. 结束录制。

**此时按“C. 分支”判断。**

### S7 删除漏网的测试句（仅分支 C，原始片段 `P3-S7.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
测试句“只要量得准就能治愈高血压”仍出现在正式文章或HTML预览里。它在事实卡中无对应，请从正式文章和HTML预览中删除，只保留在核验表的删除前后对照里作为反例。更新同名文件。
```

3. 停 3 秒。**标记 M7-1**。发送，等待完成。
4. 重新打开 .html 预览，滚到原来出现测试句的位置，停 4 秒。**标记 M7-2**。
5. 结束录制。

## C. 分支

S6 结束后检查（`$WS/演示输出/P3/`）：

```sh
cd "$WS/演示输出/P3"
grep -l "治愈" *核验*.md                         # 核验表应该提到测试句
grep -n -E "无对应|不支持" *核验*.md | head
grep -n "治愈" $(ls *.md *.html | grep -v 核验)  # 正式文章 / HTML 里应只在反例说明或对照框里出现
```

- 核验表里测试句判为“无对应 / 不支持”，且正式文章和 HTML 的正文里没有“只要量得准就能治愈高血压”这句（只在“删除前后对照 / 反例 / 已删除”这类说明里出现可以）→ **主线**。不录 S7。
- 测试句还在正式文章或 HTML 的正文段落里 → **分支 C**：录 S7，剪辑时在镜头 11 后插入镜头 11C。
- 核验表把测试句判成了“支持”→ 这是严重错误，照实录下来；在 S7 的指令前加一句“测试句在事实卡中没有任何对应，不能判为支持。”，在 report.md 写明。
- 有 M5-4（某句被收窄或删除）→ 剪辑时在镜头 11 之后插入镜头 11D；没有就不用。

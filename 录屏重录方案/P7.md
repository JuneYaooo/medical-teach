# P7 患教单与随访材料 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P7-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 30 秒 – 3 分 15 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/教学事实卡.csv` |
| 这一段要教会 | ① 患教单只写有来源的内容；② 随访日期、电话、测量频次这类需要医生定的，留空让医生填；③ 用“回授法”（让患者复述）找出容易误解的句子；④ 改后导出 PDF，确认一页 A4、没有裁切；⑤ AI 模拟的复述不能代替真人试读 |

旧录屏的问题：56 秒，后 41 秒都在预览患教单，看不出“回授修改”改了哪一句；“测两次”被理解成“一天测两次”这个最好懂的例子没有前后对比；医嘱填写栏没有单独展示。

---

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P7"
mkdir -p 录屏重录方案/_work/P7/raw
```

在 WorkBuddy 里：关闭右侧所有标签页；左侧任务列表清空或收起；确认统一模型。

---

## B. 录制步骤

### S1 写患教单（原始片段 `P7-S1.mp4`）

1. 开始录制。点左上角“新建任务”，确认输入框下方显示 `WorkBuddy教程`。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
根据实操素材/教学事实卡.csv写一页A4大字教学患教单，只用有来源内容。随访日期、科室电话和个体测量频次缺少医嘱就留填写栏；不要编急诊阈值或停药建议。医生签署未完成，明确为教学草稿。
```

3. 停 3 秒。**标记 M1-1**。
4. 发送，等待完成。出现患教单文件卡片（或回复里出现完整患教单）时 **标记 M1-2**。
5. 结束录制。

### S2 看第一版（原始片段 `P7-S2.mp4`）

1. 开始录制。
2. 点击患教单文件卡片打开预览（没有文件卡片就在左栏回复里看）。停在标题区 3 秒。**标记 M2-1**。
3. 滚动到“怎么测”一节，停在写“两次”的那一句 4 秒。**标记 M2-2**。
4. 滚动到医嘱填写栏（随访日期、科室电话、一天测几次、医生签名），停 5 秒。**标记 M2-3**。
5. 结束录制。

**此时按“C. 分支”判断。**

### S3 模拟患者复述并修改（原始片段 `P7-S3.mp4`）

1. 开始录制。点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
模拟患者回述：指出“测两次”可能被误解为一天两次，应改成“每次测量取两次读数，间隔1分钟；一天测几次按医生安排”。把修改纳入患教单，输出一页HTML及可生成的Word/PDF、电话和微信随访话术、回授前后对照到演示输出/P7/。AI模拟不等于真实患者测试。
```

2. 停 3 秒。**标记 M3-1**。
3. 发送，等待完成。出现多个文件卡片时 **标记 M3-2**。
4. 结束录制。

> 如果 WorkBuddy 导出 PDF 时要用 LibreOffice 并询问能否删除或改动用户配置，回复下面这句（旧录屏实际使用的原文），这一段剪辑时加速带过：
>
> ```text
> LibreOffice重算/导出若需要，请使用独立临时UserInstallation目录，不删除用户Library配置或无关文件。
> ```

### S4 看回授对照（原始片段 `P7-S4.mp4`）

1. 开始录制。
2. 点击回授对照文件卡片（类似 `P7-回授模拟与前后对照.md`）。停在“回授场景”那几行对话 5 秒（能看到模拟患者说“一天测两次”）。**标记 M4-1**。
3. 滚动到“修改前后对照”表格，停 5 秒。**标记 M4-2**。
4. 结束录制。

### S5 看修改后的患教单和 PDF（原始片段 `P7-S5.mp4`）

1. 开始录制。
2. 点击患教单 HTML 文件卡片（类似 `P7-患教单.html`），滚动到“怎么测”一节写“两次读数”的那一句，停 4 秒。**标记 M5-1**。
3. 滚动到“请医生填写”的表格，停 4 秒。**标记 M5-2**。
4. 点击 PDF 文件卡片（类似 `P7-患教单.pdf`），等预览出现整页，停 4 秒（能看到页面边缘和页数）。**标记 M5-3**。
5. 点击随访话术文件卡片（类似 `P7-随访话术.md`），停在电话话术开头 3 秒。**标记 M5-4**。
6. 结束录制。

## C. 分支

S2 结束后，读第一版患教单（`$WS/演示输出/P7/` 下的 .html 或 .md；没有文件就 OCR 左栏回复）里含“两次”的句子：

- 句子里有“测两次”“量两次”，但**没有**“读数”且**没有**“间隔”→ **主线**：第一版有歧义，剪辑时用镜头 5（黄框原句）。
- 第一版已经写成“每次测量取两次读数、间隔 1 分钟”→ **分支 B**：S3 照样录（它还要生成回授对照和 PDF），剪辑时镜头 5 换成 5B。

S3 结束后检查 `$WS/演示输出/P7/` 下是否有 .pdf：

- 没有 → 在 report.md 记录；剪辑时去掉镜头 10，镜头 11 旁白改用 11B。

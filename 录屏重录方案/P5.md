# P5 图文与海报 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P5-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 00 秒 – 3 分 30 秒（旧录屏 2 分 25 秒里有 77 秒在滚动，这次要压缩滚动、增加讲解） |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/教学事实卡.csv`（F01–F10） |
| 这一段要教会 | ① 先出逐页方案：每页一个要点、图上文字、F 编号、禁用元素；② 做成 HTML 后**逐页看**，发现文字压在图形上、措辞和事实卡不一致就让 AI 改；③ 图上每行字逐字对回事实卡；④ 海报保留来源和“教学草稿”标记 |

旧录屏的问题：最长的一段，但大部分时间在上下滚动；本课核心“发现文字与图形重叠”在画面上看不出重叠在哪、改后差别不明显；没有逐字对照事实卡的画面。

参考结果（`WorkBuddy教程/演示输出/P5/`）的六页：① 选对血压计（F03）② 测前 30 分钟三个不（F04）③ 测前排空 + 休息（F05）④ 戴对袖带、坐正（F06、F07）⑤ 安静、每次两次（F08、F09）⑥ 带记录去随访（F01、F02、F10）。上次第一版的问题：第 2 页图上文字和深色遮罩重叠、第 1 页图形被遮挡；第 2 页把 F04 的“含咖啡因饮料”简写成“不喝咖啡因”。

## B. 录制步骤

### S1 先出逐页方案（原始片段 `P5-S1.mp4`）

1. 开始录制，画面在 WorkBuddy 首页。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 选择（剪辑时去掉）。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
根据实操素材/教学事实卡.csv设计6页家庭血压测量教学图文，每页一个要点，含标题、图上文字、F编号、版式说明和禁用元素。用大字号、高对比，图像不要包含品牌或错误人体结构。先给逐页方案。
```

4. 停 3 秒。**标记 M1-1**。
5. 发送，等待生成完成。**标记 M1-2**。
6. 在左栏回复（或它生成的方案文件）里滚到第 2 页的方案（含 F04），停 5 秒，能同时看到这一页的标题、图上文字、F 编号、禁用元素。**标记 M1-3**。
7. 结束录制。

### S2 做成 HTML 图文和海报（原始片段 `P5-S2.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
把核验后的文字制作成可本地打开的6页HTML图文和一张1080×1920竖版HTML海报，文字使用真实文字层，保留教学草稿标记与来源链接。逐字对照事实卡，保存方案、设计需求单、HTML和文字核对表到演示输出/P5/。
```

3. 停 3 秒。**标记 M2-1**。
4. 发送，等待生成完成。回复里出现图文 HTML、海报 HTML、文字核对表等文件卡片时 **标记 M2-2**。
5. 结束录制。

### S3 逐页查看第一版（原始片段 `P5-S3.mp4`）

1. 开始录制。
2. 点击 6 页图文的 HTML 文件卡片（文件名类似 `P5-教学图文-6页.html`），右侧预览打开。
3. 从第 1 页开始，每次滚动一页，让该页完整（或尽量完整）显示在预览区，停 3 秒。依次**标记 M3-1 … M3-6**（第 1 到第 6 页停留开始的时刻）。
4. 结束录制。

### S3-检查 用程序检查重叠（不录制）

S3 录完后，运行下面的检查。它在无头浏览器里打开图文 HTML，找出“文字框和图形框相交”或“两段文字互相重叠”的地方，并给每页截图：

```sh
python3 - <<'EOF'
import glob, json, os
from playwright.sync_api import sync_playwright
WS = os.path.expanduser('~/WorkBuddy录制/WorkBuddy教程/演示输出/P5')
OUT = '录屏重录方案/_work/P5/check'
html = [f for f in glob.glob(WS + '/*.html') if '海报' not in f][0]
JS = r'''() => {
  const vis = e => { const s = getComputedStyle(e); return s.visibility !== 'hidden' && s.display !== 'none' && +s.opacity > 0.05; };
  const texts = [...document.querySelectorAll('body *')].filter(e =>
      [...e.childNodes].some(n => n.nodeType === 3 && n.textContent.trim()) && vis(e) && !e.closest('svg'));
  const figs = [...document.querySelectorAll('svg, img, canvas')].filter(vis);
  const R = e => e.getBoundingClientRect();
  const hit = (a, b) => { const x = Math.min(a.right, b.right) - Math.max(a.left, b.left), y = Math.min(a.bottom, b.bottom) - Math.max(a.top, b.top); return x > 4 && y > 4 ? x * y : 0; };
  const out = [];
  for (const t of texts) {
    const r = R(t);
    for (const f of figs) if (!f.contains(t) && !t.contains(f) && hit(r, R(f)) > 0.2 * r.width * r.height)
      out.push({type: '文字压图形', text: t.textContent.trim().slice(0, 30), y: Math.round(r.top + scrollY)});
    for (const u of texts) if (u !== t && !u.contains(t) && !t.contains(u) && hit(r, R(u)) > 0.2 * r.width * r.height)
      out.push({type: '文字叠文字', text: t.textContent.trim().slice(0, 30) + ' / ' + u.textContent.trim().slice(0, 30), y: Math.round(r.top + scrollY)});
  }
  // svg 内部文字被遮罩盖住：svg 里的 text 与其后绘制的不透明 rect 相交
  document.querySelectorAll('svg text').forEach(t => {
    const r = R(t);
    [...t.ownerSVGElement.querySelectorAll('rect, path')].filter(p => t.compareDocumentPosition(p) & 4)
      .forEach(p => { if (hit(r, R(p)) > 0.3 * r.width * r.height) out.push({type: 'SVG 文字被覆盖', text: t.textContent.trim().slice(0, 30), y: Math.round(r.top + scrollY)}); });
  });
  return out;
}'''
with sync_playwright() as p:
    b = p.chromium.launch(); pg = b.new_page(viewport={'width': 1080, 'height': 1400})
    pg.goto('file://' + html); pg.wait_for_timeout(800)
    res = pg.evaluate(JS)
    pg.screenshot(path=f'{OUT}/全页.png', full_page=True)
    b.close()
json.dump(res, open(f'{OUT}/overlap.json', 'w'), ensure_ascii=False, indent=1)
print(len(res), '处疑似重叠'); [print(r) for r in res[:20]]
EOF
```

- 输出里的 `y` 是这段文字距页面顶部的像素，用它和 `全页.png` 对照，确定在第几页。
- 再人工看一遍 `全页.png`：文字是否压在图形上、是否有被深色块盖住的半透明文字（旧版第 2 页就是这种“重影”）。程序没报但肉眼看到的，也算重叠。
- 同时做措辞检查：

```sh
grep -o -E "不喝咖啡因[^饮]|测两次|量两次" "$WS/演示输出/P5/"*.html | sort | uniq -c
```

  命中“不喝咖啡因”（后面不是“饮料”）或“测两次 / 量两次”（没说“读数”“间隔 1 分钟”），记为**措辞问题**。

把发现的问题写入 report.md，然后按“C. 分支”决定录哪一步。

### S4 提出版式和措辞修订（仅主线，原始片段 `P5-S4.mp4`）

1. 开始录制。画面停在 S3 里有重叠的那一页（预览区），停 3 秒。**标记 M4-1**。
2. 点击输入框，粘贴下面的修订指令。先把 `【 】` 里的内容按 S3-检查的结果替换（只替换括号部分，其余原样；没有措辞问题就删掉“；第2页……”到“遵医嘱”这一句）：

```text
实际预览发现【第2页SVG底部文字与深色overlay重叠，第1页图形也被覆盖】。请修正6页图文：figure改为纵向文档流，overlay不要absolute覆盖SVG，重复标签只保留一份，全部六页检查不重叠；第2页“不喝咖啡因”改“不喝含咖啡因饮料”；第4页明确“袖带中部与心脏同高”；第5页写“每次两次、间隔1分钟”，一天频次仍遵医嘱。竖版海报也检查真实文字层可读、不要与图形重叠。保存同名文件并打开预览。
```

   （上面是旧录屏实际输入的原文，括号里是当时的问题描述，替换成本次实际发现的页码和现象。）
3. 停 3 秒。**标记 M4-2**。
4. 发送，等待完成。
5. 点击更新后的同名 HTML 文件卡片，滚到同一页，停 5 秒。**标记 M4-3**。
6. 结束录制。
7. 修订后**再运行一次 S3-检查**。仍有重叠就再发一次同一指令（不录制或录后剪掉等待），最多两次；仍不行就在 report.md 记录，剪辑时只展示改善最明显的一页。

### S5 快速翻完六页（原始片段 `P5-S5.mp4`）

1. 开始录制（修订后的版本；分支 B 时用第一版）。
2. 在图文 HTML 预览里，从第 1 页到第 6 页，每页完整显示后停 3 秒再滚到下一页。依次**标记 M5-1 … M5-6**。
3. 结束录制。

### S6 逐字对照事实卡（原始片段 `P5-S6.mp4`）

1. 开始录制。
2. 点击文字核对表文件卡片（文件名含“核对”），右侧预览打开。滚到 F09 那一行，停 4 秒。**标记 M6-1**。
3. 点开图文 HTML 标签页，滚到第 5 页（含 F09 的那页），停 4 秒，让“间隔 1 分钟”那行字在画面上。**标记 M6-2**。
4. 结束录制。

### S7 看竖版海报（原始片段 `P5-S7.mp4`）

1. 开始录制。
2. 点击海报 HTML 文件卡片（文件名含“海报”、“1080x1920”），右侧预览打开；点预览区右上角放大图标铺满窗口。停在顶部 3 秒。**标记 M7-1**。
3. 每次滚动半屏，慢慢滚到底部，总共不超过 15 秒。到底部（来源链接、“教学草稿”标记、F01 警示条）后停 4 秒。**标记 M7-2**。
4. 结束录制。

## C. 分支

S3-检查之后：

- `overlap.json` 有记录，或人工看截图发现重叠，或有措辞问题 → **主线**，录 S4，然后录 S5–S7。镜头 6–8 用主线版本。
- 都没有 → **分支 B**：不录 S4，S5 用第一版直接录。镜头 6–8 换成“分支 B 镜头”。
- 只有措辞问题、没有重叠 → 仍走主线，但 S4 的指令里删掉“实际预览发现……检查不重叠；”这一段，只保留措辞修改和最后一句；镜头 6 画面改为黄框标出措辞问题那一行，旁白改用 6W。
- 六页里任一页的 F 编号和参考结果不同（例如 F07 放在第 3 页）不算错误，只要文字核对表里逐字一致即可；旁白里的页码按实际改。

# R1 文献情报与选题 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/R1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 15 秒 – 4 分 00 秒 |
| 前置产物 | 无（需要 01 课已完成：工作空间可选、能联网） |
| 用到的素材 | `实操素材/模拟医生定位.txt`、`实操素材/来源索引.md` |
| 这一段要教会 | ① 把模糊方向拆成可测量的 PICO 问题，划掉测不到的结局；② 让 AI 真实检索并给出 PMID；③ 自己去 PubMed 打开 PMID 核对；④ 发现 AI 把“组内变化”“次要终点”说过头，让它改；⑤ 看到两社区设计的混杂风险 |

旧录屏的问题：2 分 13 秒大部分在滚动 PICO 表和文献清单；纠正环节只是一大段对话文字，看不出改了哪句；没有“去 PubMed 官网核对 PMID”这个动作。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/R1"
mkdir -p 录屏重录方案/_work/R1/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

浏览器：打开一个干净窗口（无书签栏、无其他标签页），窗口 1440×900，先停在空白页，S5 再用。

## B. 录制步骤

### S1 提出 PICO 任务（原始片段 `R1-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 重新选择（剪辑时去掉）。
3. 点击输入框，粘贴（原样，不改一字）：

```text
当前工作空间：WorkBuddy教程。
我们计划在两家社区开展家庭血压监测研究，总周期12个月。请结合实操素材/来源索引.md，提出3个可测量的研究问题，分别列出PICO、主要结局、随访要求、资源需求和可行性。说明当前条件不能回答的问题，给出推荐方向及理由，保存研究问题对比表和PICO到演示输出/R1/。
```

4. 停 3 秒。**标记 M1-1**（提示词完整显示）。
5. 点发送。等待生成完成（README 4.3）。回复里出现 `PICO.md` 文件卡片时，**标记 M1-2**。
6. 停 2 秒，结束录制。

### S2 看 PICO 结果（原始片段 `R1-S2.mp4`）

1. 开始录制。
2. 在左侧回复里滚动到 3 个研究问题的表格（编号 1/2/3、研究问题、结局），停 4 秒。**标记 M2-1**。
3. 点击 `PICO.md` 文件卡片，右侧预览打开。滚动到“教学资源边界”表里的“不可用数据”一行，停 4 秒。**标记 M2-2**。
4. 结束录制。

### S3 选定问题并检索（原始片段 `R1-S3.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
选定家庭血压自测支持的基层管理主题。请构造并执行PubMed检索，筛选5篇最相关的原始研究或综述；记录检索日期、完整检索式、筛选理由、PMID、题目、年份、研究设计、主要发现和来源链接，区分摘要与全文。核对PMID 29499873是否适用于我们的研究问题。完成文献清单和一页选题简报，包含证据缺口、可行的切入点与下一步资料需求，保存到演示输出/R1/。无法访问的来源如实记录。
```

3. 停 3 秒。**标记 M3-1**。
4. 点发送。回复里第一次出现调用 PubMed / E-utilities / 联网检索的工具提示时，**标记 M3-2**。
5. 等待生成完成。出现 `文献清单.md` 和 `选题简报.md` 两个文件卡片时，**标记 M3-3**。
6. 停 2 秒，结束录制。

### S4 看文献清单（原始片段 `R1-S4.mp4`）

1. 开始录制。
2. 点击 `文献清单.md` 文件卡片。滚动到文献表格，停在包含 `29499873` 的那一行 4 秒。**标记 M4-1**。
3. 继续滚动到“各篇与问题的对应点”（或类似的逐篇说明）段落，停 5 秒。**标记 M4-2**。
4. 结束录制。

### S5 去 PubMed 核对 PMID（原始片段 `R1-S5.mp4`）

1. 开始录制，画面在浏览器空白页。
2. 在地址栏粘贴并回车：

```text
https://pubmed.ncbi.nlm.nih.gov/29499873/
```

3. 页面加载完成后，停在题目、期刊年份（Lancet 2018）区域 4 秒。**标记 M5-1**。
4. 结束录制。剪辑时与 S4 的 M4-1 并排。

### S6 看选题简报（原始片段 `R1-S6.mp4`）

1. 开始录制，画面回到 WorkBuddy。
2. 点击 `选题简报.md` 文件卡片。滚动到“检索所得文献给出的讨论锚点”（或“有效性”）段落，停 5 秒。**标记 M6-1**。
3. 继续滚动到“设计风险 / 局限”相关段落（如有），停 4 秒。**标记 M6-2**。
4. 结束录制。

**此时按“C. 分支”判断走哪条线。**

### S7 发出人工复核纠正（主线 / 分支 C，原始片段 `R1-S7.mp4`）

1. 开始录制。
2. 点击输入框，粘贴下面其中一段（主线用第一段，分支 C 用第二段）：

主线（上次实操实际输入的纠正文字）：

```text
人工复核后的修改：保留5篇并将TASMINH4作为补充。PMID39250514摘要仅报告组内变化与相关性，请把“系统使……下降”改为“干预组内观察到血压下降”，不得据此推断组间因果效果，家庭/诊室测量方式未查清则注明待全文核对。ASPIRE的主要终点是可行性与实施忠实度，血压变化为次要终点；摘要未明确测量地点时不能写成与家庭自测结局完全同构。两社区各一组不能排除社区差异混杂，请在选题简报写明，暂不当作确定设计。更新原交付文件，保存修改依据。
```

分支 C（这次检索到的文献不是 PERHIT / ASPIRE 时使用）：

```text
人工复核后的修改：逐篇检查选题简报里引用的每篇文献。凡是摘要只报告干预组自身前后变化、没有和对照组比较的，改写为“干预组内观察到……”，不得写成干预有效或组间因果效果；凡是血压只是次要终点或试点研究的，写明终点级别和样本量。两社区各一组不能排除社区差异混杂，请在选题简报写明，暂不当作确定设计。更新原交付文件，保存修改依据。
```

3. 停 3 秒。**标记 M7-1**。
4. 点发送，等待完成。
5. 点击更新后的 `选题简报.md`，滚动到改后的那几句（含“组内”“次要终点”）停 5 秒。**标记 M7-2**。
6. 滚动到含“混杂”的段落停 4 秒。**标记 M7-3**。
7. 结束录制。

## C. 分支

S6 结束后，读 `$WS/演示输出/R1/选题简报.md` 和 `$WS/演示输出/R1/文献清单.md`：

- **主线**：文件里出现 `39250514` 或 `PERHIT`，并且描述它时**没有**出现“组内”二字（例如写成“显著降低”“使……下降”）；或者出现 `40562882` / `ASPIRE` 却没有写“次要终点”→ 发 S7 主线纠正文字。
- **分支 C**：两篇都没出现，但简报里有某篇文献被写成“证明有效 / 显著降低”，而 `文献清单.md` 对应说明里只有组内前后比较或“试点 / pilot”→ 发 S7 分支 C 纠正文字。
- **分支 B**：简报里所有文献描述都已区分“组内变化 / 组间差异”和“主要 / 次要终点”，并且已写出“混杂”风险 → 跳过 S7，镜头 12–14 换成下面的分支 B 镜头。
- 不管哪条线，`文献清单.md` 里没有 `29499873` 或 PubMed 页面题目与清单对不上 → 在 report.md 记录，旁白镜头 9 改为“对不上，就要让它重新检索”，并补录一次重新检索。

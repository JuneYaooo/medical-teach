# P4 短视频脚本与分镜 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P4-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 30 秒 – 3 分 15 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/教学事实卡.csv` 的 F05、F08、F09 |
| 这一段要教会 | ① 把三条事实压成 30 秒脚本时，限定条件不能丢（休息至少 5 分钟、测时不说话不用手机、两次读数间隔 1 分钟）；② 删掉事实卡里没有的评价句；③ 分镜每个镜头的秒数是估计值，配音后要重新校准 |

旧录屏的问题：54 秒，后 37 秒都在看一张宽表，字小；三种开头没有对比；“删掉笼统评价句”这一处修改没有出现。

参考结果（`WorkBuddy教程/演示输出/P4/`）：定稿 5 个镜头，预估 4、7、7、6、6 秒，合计 30 秒；删掉了两句评价句——“先记住，安静这件事，从测前到测中都很重要。”“方法对了，读数才有参考价值。”

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P4"
mkdir -p 录屏重录方案/_work/P4/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 写脚本和三种开头（原始片段 `P4-S1.mp4`）

1. 开始录制，画面在 WorkBuddy 首页。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 选择（剪辑时去掉）。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
请用实操素材/教学事实卡.csv的F05、F08、F09，写一条给家庭血压测量者看的约30秒短视频脚本。提供患者问法、生活场景、直接提问三个开头，正文围绕测前休息、测量时安静、每次两次读数展开。分别提供可直接口播的正文和带F编号的核对稿，字数与时长注明估计依据。
```

4. 停 3 秒。**标记 M1-1**。
5. 发送，等待生成完成。**标记 M1-2**（完成时）。
6. 在左栏回复里（或打开它生成的脚本文件）滚到“三个开头”，停 5 秒，三种开头要同时在画面里。**标记 M1-3**。
7. 继续滚到正文（带【F05】【F08】【F09】的几句），停 5 秒。**标记 M1-4**。
8. 结束录制。

### S2 选开头、出分镜、做核验（原始片段 `P4-S2.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（最后一行是旧录制时实际追加的要求，保留）：

```text
当前工作空间：WorkBuddy教程。
选择生活场景开头。请精简重复铺垫并保留准确含义，完成5个镜头的分镜表，逐镜列画面、口播、屏幕文字、动作、景别、道具和预计时长，总计约30秒。逐句核对医学表述、统计口播字数并调整节奏，交付脚本、分镜CSV、拍摄准备清单及核验表到演示输出/P4/。
只用事实卡支持的完整含义，不增加新医学事实。保存精简且可用的三个文件。
```

3. 停 3 秒。**标记 M2-1**。
4. 发送，等待生成完成。出现脚本（.md）、分镜（.csv）、核验表三个文件卡片时 **标记 M2-2**。
5. 结束录制。

### S3 看删改清单（原始片段 `P4-S3.mp4`）

1. 开始录制。
2. 点击脚本文件卡片（.md，文件名含“脚本”），右侧预览打开。
3. 滚动到“删改清单”或“修改前后对照”表（关键词：`删改`、`删除`、`整句删除`），停 6 秒，整张表要完整在画面里。**标记 M3-1**。
4. 滚动到“定稿旁白”，停 4 秒。**标记 M3-2**。
5. 结束录制。

**此时按“C. 分支”判断走主线还是分支 B / C。**

### S4 删除评价句（仅分支 C，原始片段 `P4-S4.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
定稿脚本里还有不带F编号的评价性句子（例如“……很重要”“……才有参考价值”）。事实卡没有这些论断，而且会挤占30秒里的停顿时间。请整句删除，并在脚本里加一张删改清单：删改前、处理、理由。分镜CSV和核验表同步更新，时长总计仍为30秒。
```

3. 停 3 秒。**标记 M4-1**。发送，等待完成。
4. 重新打开脚本文件，滚到删改清单，停 6 秒。**标记 M4-2**。
5. 结束录制。

### S5 逐个镜头看分镜（原始片段 `P4-S5.mp4`）

1. 开始录制。
2. 点击分镜 .csv 文件卡片，右侧预览打开；点预览区右上角放大图标铺满窗口。停在表头 3 秒。**标记 M5-1**。
3. 鼠标依次停在镜头 1 到镜头 5 每一行，每行 4 秒（鼠标放在“时长”那一格上）。依次**标记 M5-2、M5-3、M5-4、M5-5、M5-6**（每行开始停留的时刻）。
4. 结束录制。

### S6 看核验表（原始片段 `P4-S6.mp4`）

1. 开始录制。
2. 点击核验表文件卡片（文件名含“核验”），停在表格开头 4 秒。**标记 M6-1**。
3. 滚到写“预估”“非实测”的那一处说明（关键词：`预估`、`实测`），停 4 秒。**标记 M6-2**。
4. 结束录制。

## C. 分支

S3 结束后检查 `$WS/演示输出/P4/`：

```sh
cd "$WS/演示输出/P4"
grep -n -E "删改|整句删除|删除" *.md | head                         # 有没有删改清单
grep -n -E "很重要|才有参考价值|更准确|更健康|效果更好|放心" *.md | head  # 定稿里还有没有评价句
python3 - <<'EOF'
import csv, glob, re
f = glob.glob('*.csv')[0]
rows = list(csv.DictReader(open(f, encoding='utf-8-sig')))
col = [k for k in rows[0] if '时长' in k][0]
print(len(rows), '个镜头', sum(float(re.findall(r'[\d.]+', r[col])[0]) for r in rows), '秒')
EOF
```

- 脚本里有删改清单，且清单里至少删掉了一句评价句 → **主线**，不录 S4，镜头 8 用 S3 M3-1。
- 没有删改清单，但定稿旁白里还留着评价句（第二条 grep 在“定稿”部分有命中）→ **分支 C**：录 S4，镜头 8 改用 S4 M4-2，并在镜头 8 之前插入镜头 7C。
- 没有删改清单，定稿里也没有评价句（它一开始就没写）→ **分支 B**：不录 S4，镜头 8 换成镜头 8B。
- 镜头数不是 5 或总时长不是 30 秒 → 加录一段纠正，粘贴 `分镜表应为5个镜头、时长总计30秒，请调整每个镜头的预估秒数并同步更新CSV和核验表。`，在 report.md 记录；旁白里的秒数按实际改。
- 旁白里的 4、7、7、6、6 秒和两句被删句，都以实际文件为准改写。

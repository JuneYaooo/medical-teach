# P2 患者高频问题选题库 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P2-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 45 秒 – 3 分 30 秒 |
| 前置产物 | 无（P1 的定位结论只在旁白里提到，不依赖文件） |
| 用到的素材 | `实操素材/模拟患者问题.csv`（36 条原话，频次合计 353）、`实操素材/模拟医生定位.txt` |
| 这一段要教会 | ① 合并同义问题时保留患者原话和来源编号，频次总数不能变；② 总分用 Excel **公式**算，改一项分数总分会跟着变；③ 高风险题单独放进“待医生复核”，不直接发、不删除 |

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P2"
mkdir -p 录屏重录方案/_work/P2/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

**避免“删除缓存”插曲**：旧录制时 WorkBuddy 为了用 LibreOffice 重算公式，尝试删除 `~/Library/Application Support/LibreOffice/` 下的缓存，弹出“删除文件命中询问规则，需要确认”。录制前先在一个**不录制**的临时任务里执行一次下面的指令，让 LibreOffice 完成首次初始化，然后删掉这个临时任务和它生成的文件：

```text
当前工作空间：WorkBuddy教程。
用LibreOffice把一个只含公式=1+1的临时xlsx重算一次并读出结果，文件放在演示输出/_tmp/，完成后删除演示输出/_tmp/。不要删除工作区以外的任何文件。
```

```sh
rm -rf "$WS/演示输出/_tmp"
```

## B. 录制步骤

### S1 看一眼患者原话（原始片段 `P2-S1.mp4`）

1. 在 Finder 里选中 `~/WorkBuddy录制/WorkBuddy教程/实操素材/模拟患者问题.csv`，右键 → 打开方式 → Numbers（没有就用 Excel），窗口 1440×900。
2. 开始录制。停在表格顶部 3 秒，能看到列名“编号、问题、模拟频次、场景”。**标记 M1-1**。
3. 鼠标移到 Q04 行“袖带隔着衣服行吗”，停 2 秒；再向下滚到 Q35 行“量血压前要脱外套吗”，停 2 秒。**标记 M1-2**（停在 Q35 时）。
4. 结束录制，关闭表格窗口（不保存）。

### S2 合并同义问题（原始片段 `P2-S2.mp4`）

1. 开始录制，画面在 WorkBuddy 首页。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 选择（剪辑时去掉）。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
读取实操素材/模拟患者问题.csv和模拟医生定位.txt。保留问题原话并合并同义问题，保留来源编号，聚合频次。按家庭测量、记录随访、特殊情况与就医沟通分类。证据未查就标待核验，不能自动写有指南。
```

4. 停 3 秒。**标记 M2-1**。
5. 发送，等待生成完成。
6. 在左栏回复里滚到合并结果，找到写“合并后多少个选题”和“频次合计”的地方（关键词：`353`、`合计`、`36`），停 4 秒。**标记 M2-2**。找不到合计数字就停在聚类表的开头，并在 report.md 记录。
7. 再滚到任意一行显示“Q04,Q35”（或其他多个来源编号合并在一起）的地方，停 3 秒。**标记 M2-3**。
8. 结束录制。

### S3 生成 Excel 选题库（原始片段 `P2-S3.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（最后一行是旧录制时实际追加的要求，保留）：

```text
当前工作空间：WorkBuddy教程。
生成至少30题的Excel选题库（原数据足够才保留30），列需求0–2、专业匹配0–1、证据充分0–1、重要性0–1、风险扣分0–1，并用公式计算max(0,min(5,合计))。高风险题放入待医生复核表，不直接发布或删除来源。加状态下拉、色阶、分表，输出到演示输出/P2/。
为主表和高风险表保留来源编号关联，公式结果与文本状态一致。
```

3. 停 3 秒。**标记 M3-1**。
4. 发送，等待生成完成。
5. **如果出现“删除文件……需要确认”的确认框**：点“拒绝”，立刻结束录制，删掉这个片段，按“C. 分支”的“删除确认”处理后从 S3 第 1 步重录。
6. 回复里出现 `P2-患者高频问题选题库.xlsx`（或其他 .xlsx）文件卡片时，**标记 M3-2**。结束录制。

### S4 演示公式联动（原始片段 `P2-S4.mp4`）

1. 开始录制。
2. 点击 .xlsx 文件卡片，在右侧预览打开（WorkBuddy 自带表格预览有编辑栏）。点右上角“展开”图标把预览放大到整个窗口（旧截图里在预览区右上角）。
3. 点底部分表标签“选题总库”。停 3 秒，能看到表头和第一批题目。**标记 M4-1**。
4. 找到表头为“合计”的列（参考结果里是 N 列，表头在第 3 行；以实际为准，用 OCR 找“合计”）。点击第一行题目对应的合计单元格（参考结果里是 `N4`）。停 4 秒，让顶部编辑栏显示公式（应以 `=MAX(0,MIN(5,` 开头）。**标记 M4-2**。
5. 找到同一行表头为“重要性”的单元格（参考结果里是 `L4`，原值 1）。点击它，输入 `0`，按回车。停 4 秒，合计单元格应减少 1（参考结果里 5 → 4）。**标记 M4-3**。
6. 按 `Cmd+Z` 撤销，合计恢复原值，停 2 秒。**标记 M4-4**。不要保存。
7. 如果 WorkBuddy 预览不能编辑：关闭预览，在 Finder 里用 Numbers/Excel 打开 `$WS/演示输出/P2/` 下的 .xlsx，重做第 3–6 步，关闭时选“不存储”。在 report.md 记录用的是哪个软件。
8. 结束录制。

### S5 看分表、下拉和色阶（原始片段 `P2-S5.mp4`）

1. 开始录制（继续在同一个表格里）。
2. 在“选题总库”里，鼠标慢慢移到“聚合频次”列（有蓝色深浅色阶），停 3 秒。**标记 M5-1**。
3. 点击表头为“状态（下拉）”列的第一行单元格，点它右侧的下拉箭头，让选项（候选、待核验、待医生复核、暂缓等）展开，停 3 秒；按 `Esc` 收起，不改值。**标记 M5-2**。
4. 点底部分表标签“待医生复核”，停 4 秒，能看到这张表里的全部题目（参考结果为 6 题：停药、忘服药、头晕但数字正常、孕期设备、儿童袖带、目标值与网上不同）。**标记 M5-3**。
5. 点底部分表标签“分类汇总”，停 4 秒，能看到合计行（选题数 30、聚合频次 353）。**标记 M5-4**。
6. 结束录制。

## C. 分支

S3 结束后，用 Python（openpyxl）检查 `$WS/演示输出/P2/` 下的 .xlsx：

```sh
python3 - <<'EOF'
import glob, openpyxl
f = glob.glob('/Users/'+__import__('getpass').getuser()+'/WorkBuddy录制/WorkBuddy教程/演示输出/P2/*.xlsx')[0]
wb = openpyxl.load_workbook(f)
print(wb.sheetnames)
ws = wb[[n for n in wb.sheetnames if '总库' in n][0]]
hdr = {c.value.split('\n')[0] if c.value else '': c.column_letter for row in ws.iter_rows(max_row=5) for c in row}
col = hdr.get('合计'); print('合计列', col)
vals = [ws[f'{col}{r}'].value for r in range(1, ws.max_row+1)]
print('公式数', sum(isinstance(v,str) and v.startswith('=') for v in vals))
EOF
```

- 合计列的单元格是公式（以 `=` 开头），且有含“复核”的分表 → **主线**，录 S4、S5。
- 合计列是写死的数字（公式数为 0）→ **分支 B**：在 S4 之前加录片段 `P2-S3b.mp4`：点击输入框，粘贴下面的文字，停 3 秒（**标记 M3b-1**），发送，等完成：

```text
选题总库的合计列现在是写死的数字。请改为Excel公式=MAX(0,MIN(5,需求+专业匹配+证据充分+重要性-风险扣分))，引用同一行的单元格，不要手填结果；建议状态也用公式根据分数和风险扣分得出。重算后保存同一个文件。
```

  然后照常录 S4、S5，剪辑时在镜头 7 之前插入镜头 6B。
- 没有“待医生复核”分表 → 同样加录一段纠正，粘贴：`风险扣分为1的题目请单独放进名为“待医生复核”的分表，主表保留并标注状态，不删除任何来源问题。保存同一个文件。` 剪辑时插入镜头 6C。
- **删除确认**（S3 中出现“删除文件命中询问规则”）：点“拒绝”；新建任务，先粘贴 S2 的提示词并完成，再粘贴 S3 的提示词，并在末尾另起一行加上 `所有临时文件只写到演示输出/P2/下的独立目录，不要删除工作区以外的任何文件。`。录制画面里不能出现确认框。
- 数字以实际为准：选题数不是 30、频次合计不是 353、待复核不是 6 题时，把旁白里的数字改成实际值，在 report.md 记录。**频次合计不等于 353** 说明合并时丢了或重复算了问题，这是真实错误：加录一段纠正，粘贴 `合并后的聚合频次合计应等于原表36条问题的频次总和353，请逐条核对来源编号，找出丢失或重复计算的问题并修正。`，剪辑时在镜头 5 后插入镜头 5B。

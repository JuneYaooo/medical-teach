# R4 数据清洗、统计与绘图 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/R4-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 30 秒 – 4 分 15 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/bp_trial_sim.csv`、`实操素材/数据字典与SAP.md` |
| 这一段要教会 | ① 拿到数据先体检，不动原始数据；② 人确认清洗规则后再分析；③ 看懂主要结果（均数差和置信区间）；④ 每个数字都要说清分母——268 和 269 不是一回事；⑤ 重跑脚本确认可复现 |

旧录屏的问题：64 秒、5 个章节，其中一章只有 1.3 秒；体检报告和结果表整屏滚动，异常值和重复记录没被指出；结尾混入无关的“列出课程成品产物”会话。

参考结果（`WorkBuddy教程/演示输出/R4/`）：
- 原始表 303 行，唯一受试者 300 人，3 条逐字段完全重复（第 302/303/304 行）。
- 3 个明显录错的值：`age=999`（SIM019）、`bmi=99`、`sbp_6m=18`，设为缺失、保留受试者。
- 性别一个变量里混用 6 种写法（男/M/1、女/F/0）。
- 6 个月收缩压有数据的 269 人；主模型（结局和协变量都齐全）268 人，未纳入 32 人（31 人结局缺失 + 1 人年龄 999 置缺失）。
- 调整均数差 −5.60 mmHg，95% CI −7.67 至 −3.52；HC3 区间 −7.69 至 −3.51；P<0.001。
- 数据按编号交替分组，是合成教学数据，不是真实随机化。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/R4"
mkdir -p 录屏重录方案/_work/R4/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起（尤其不能出现“列出课程成品产物”会话）；确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 只体检，不改数据（原始片段 `R4-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`。
3. 点击输入框，粘贴（原样）：

```text
当前工作空间：WorkBuddy教程。
读取实操素材/bp_trial_sim.csv和数据字典与SAP.md。先不要修改数据，不要删除记录。报告行数、唯一受试者数、15个变量字典、缺失、异常值、编码混用及重复记录；列逐条清洗建议和影响行数，等待我确认。保存体检报告到演示输出/R4/。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送，等待生成完成。出现体检报告文件卡片（如 `R4-数据体检报告.md`）时，**标记 M1-2**。
6. 停 2 秒，结束录制。

### S2 看体检报告（原始片段 `R4-S2.mp4`）

1. 开始录制。
2. 点击体检报告文件卡片，右侧预览打开。停在顶部“只读声明”4 秒。**标记 M2-1**。
3. 滚动到“结论速览”表，停在“数据行数 / 唯一受试者数 / 完全重复记录”三行 5 秒。**标记 M2-2**。
4. 继续停在“哨兵值 / 异常值”和“编码混用”两行 5 秒。**标记 M2-3**。
5. 结束录制。

### S3 回原始表看一眼（原始片段 `R4-S3.mp4`）

1. 在 Finder 里选中 `~/WorkBuddy录制/WorkBuddy教程/实操素材/bp_trial_sim.csv`，右键 → 打开方式 → Numbers（没有就用 Excel），窗口 1440×900。
2. 开始录制。停在表头 2 秒。
3. 滚动到 `SIM019` 那一行（第 20 行），点击它的 `age` 单元格（值为 999），停 4 秒。**标记 M3-1**。
4. 关闭表格（不保存），结束录制。

### S4 确认清洗规则并分析（原始片段 `R4-S4.mp4`）

1. 开始录制，画面回到 WorkBuddy 同一任务。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：WorkBuddy教程。
清洗规则确认：999岁、6个月收缩压18、BMI99设为缺失，保留该受试者；性别按字典统一；只移除逐字段完全一致的3条重复记录，冲突记录不得自行选择；不均数填补。按SAP做完整病例线性回归并明确不等于完整ITT；调整基线收缩压、年龄和中心，报告组别均数差、95%CI、P值及HC3敏感性分析。不生成未预设亚组。输出clean.csv、逐条日志、Table1（不做基线P值检验）、结果表、带单位和CI的图、analysis.py及结果Excel到演示输出/R4/。重跑脚本核对结果。
```

3. 停 3 秒。**标记 M4-1**。
4. 点发送。回复里出现运行 `analysis.py` 或执行 Python 的提示时，**标记 M4-2**。
5. 等待生成完成。出现多个文件卡片（结果表、图、analysis.py 等）时，**标记 M4-3**。
6. 停 2 秒，结束录制。

### S5 看主要结果（原始片段 `R4-S5.mp4`）

1. 开始录制。
2. 点击 `结果表.md` 文件卡片（没有卡片就点“查看所有产物”找）。滚动到“主要结果”表，停在主分析那一行 5 秒。**标记 M5-1**。
3. 滚动到“纳入者与未纳入者比较”部分（含 n=268 和 n=32 的表），停 5 秒。**标记 M5-2**。
4. 继续滚动，找到任何按结局有无划分的比较（含 269 或 31），停 4 秒。**标记 M5-3**（没有就跳过）。
5. 结束录制。

**此时按“C. 分支”判断是否录 S6。**

### S6 统一分母（仅主线，原始片段 `R4-S6.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（上次实操实际输入的复核文字）：

```text
结果复核补充：结果表的纳入/缺失特征比较目前为269/31，实际主分析为268/32（还包括年龄缺失1人）。请用同一完整病例mask比较纳入268与未纳入32，更新表、Excel和脚本；如果另列结局有无269/31，需明确标题，不能叫主分析纳入者。完整系数表的P值也不能显示0，统一<0.001或科学计数法，Excel保留真实数值。独立核算主结果MD=-5.59594634，经典CI[-7.67124336,-3.52064933]，HC3 t区间[-7.68621716,-3.50567553]，请对照。
```

3. 停 3 秒。**标记 M6-1**。
4. 点发送，等待完成。
5. 打开更新后的 `结果表.md`，滚动到纳入 / 未纳入比较表，停 5 秒。**标记 M6-2**。
6. 结束录制。

### S7 看结果图（原始片段 `R4-S7.mp4`）

1. 开始录制。
2. 点击结果图文件卡片（如 `R4-结果图.png`），停 3 秒。**标记 M7-1**。
3. 结束录制。

### S8 重跑脚本（原始片段 `R4-S8.mp4`）

1. 开始录制。
2. 在右侧预览区点“+”打开新标签页，点“打开终端”。
3. 在终端里粘贴并回车：

```text
python3 演示输出/R4/analysis.py
```

4. 运行结束后，在终端里粘贴并回车：

```text
grep -n "主分析" 演示输出/R4/结果表.md
```

5. 停 4 秒，让含 −5.60 的那一行在画面上。**标记 M8-1**。
6. 结束录制。

## C. 分支

S5 结束后，检查 `$WS/演示输出/R4/结果表.md`：

```sh
grep -n -E "(^|[^0-9.])269([^0-9]|$)|n *= *31([^0-9]|$)|(^|[^0-9.])31 *(人|例)" "$WS/演示输出/R4/结果表.md"
grep -n -E "纳入.*268|n *= *268" "$WS/演示输出/R4/结果表.md"
grep -n -E "\| *0(\.0+)? *\|" "$WS/演示输出/R4/结果表.md"
```

- **主线**（录 S6）：满足任一条——“纳入 / 未纳入”或“主分析纳入者”比较表用的是 269 / 31；按结局有无划分的表没有写明“不是主分析口径”；P 值列里出现显示为 0 的单元格。
- **分支 B**（跳过 S6）：纳入 / 未纳入比较已经是 268 / 32，且任何 269 / 31 的表都写明了按结局有无划分。剪辑表镜头 11–12 换成分支 B 镜头。
- 主要结果数字和参考值（−5.60，−7.67 至 −3.52）不一致 → 以实际为准修改旁白；同时把 S6 文字最后一句“独立核算主结果……请对照。”删掉再发送（这些数字只适用于参考数据处理方式），并在 report.md 写明。

# P1 对标调研与定位 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P1-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 30 秒 – 3 分 15 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/模拟对标内容.csv`、`实操素材/模拟医生定位.txt` |
| 这一段要教会 | ① 分析对标数据前先看清每一列是什么；② 发现 AI 把“收藏÷点赞”叫成“收藏率”、把字数和秒数混着比，让它改；③ 用自己的受众、时间、目标定出内容方向 |

旧录屏的问题：46 秒，全是文字对话和定位文档滚动；“收藏÷点赞≠收藏率”“字数和秒数混在一列”这两个坑在画面上看不到；看不出最终定位页长什么样。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P1"
mkdir -p 录屏重录方案/_work/P1/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

---

## B. 录制步骤

### S1 看一眼对标数据（原始片段 `P1-S1.mp4`）

1. 在 Finder 里选中 `~/WorkBuddy录制/WorkBuddy教程/实操素材/模拟对标内容.csv`，右键 → 打开方式 → Numbers（没有 Numbers 就用 Excel），窗口调成 1440×900。
2. 开始录制。停在表格顶部 3 秒，能看到列名“账号、标题、形式、字数或秒数、点赞、收藏、评论、标记”。**标记 M1-1**。
3. 鼠标慢慢移到“字数或秒数”这一列的列名上，停 3 秒。**标记 M1-2**。
4. 鼠标依次移到第 2 行（图文，800）和第 5 行（短视频，30）的这一列单元格上，各停 2 秒。**标记 M1-3**。
5. 结束录制，关闭表格窗口（不保存）。

### S2 输入对标分析任务（原始片段 `P1-S2.mp4`）

1. 开始录制，画面在 WorkBuddy 首页。
2. 点左上角“新建任务”（对话气泡加号图标）。确认输入框下方显示 `WorkBuddy教程`；不是的话按 01.md S1 的方法选择（剪辑时去掉这部分）。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
读取实操素材/模拟对标内容.csv。这是虚构练习，不是真实账号业绩。按账号整理题目、形式、互动数据，拆解人群、题目、标题和结构；原表没有的视觉风格、发布频率和转化路径写素材不足。先给对比表，再问我3个定位问题。
```

4. 停 3 秒。**标记 M2-1**。
5. 点发送。等待生成完成（README 4.3）。
6. 回复末尾出现“3 个定位问题”时，滚动让这 3 个问题完整显示在左栏，停 4 秒。**标记 M2-2**。
7. 回复里出现 `对标对比表.md` 文件卡片时，**标记 M2-3**。结束录制。

### S3 查看对比表（原始片段 `P1-S3.mp4`）

1. 开始录制。
2. 点击 `对标对比表.md` 文件卡片，右侧预览打开。停在顶部 3 秒。**标记 M3-1**。
3. 慢慢向下滚动，找到出现“收藏”和“点赞”一起计算的地方（关键词：`收藏率`、`收藏÷点赞`、`收藏/点赞`、`比值`），停 4 秒。**标记 M3-2**。
4. 继续向下，找到写“素材不足”的任意一处，停 3 秒。**标记 M3-3**。
5. 如果表里有按“字数或秒数”推出“多长最好 / 最佳长度”之类的结论，滚到那里停 4 秒，**标记 M3-4**；没有就跳过。
6. 结束录制。

**此时按“C. 分支”判断走主线还是分支 B。**

### S4 纠正对比表（仅主线，原始片段 `P1-S4.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
人工复核同步纠正对比表：收藏/点赞、评论/点赞是比值，不叫收藏率或评论率，更不能代表真实留存/争议。字数与秒数混列且未有正文，不能混在一起推出短长内容效果或标题对应的人群行为；删掉这些效果解读。模拟随机互动只用于读表练习，不推出选题解释度、平台规律和制作效果；保留可核验数值与素材不足项。更新同一个对标对比表。
```

3. 停 3 秒。**标记 M4-1**。
4. 发送，等待完成。
5. 点击更新后的 `对标对比表.md` 文件卡片，滚动到原来 M3-2 对应的位置，停 5 秒。**标记 M4-2**。
6. 结束录制。

### S5 回答定位问题（原始片段 `P1-S5.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
定位回答：受众是60岁以上高血压患者及照护者；每周只有2小时；希望帮助他们按正确步骤测量并带记录就诊，不做个体诊疗。结合模拟医生定位.txt，给出一页定位、3个内容支柱、适合的制作节奏、可借鉴与不能照搬之处，保存到演示输出/P1/。
```

3. 停 3 秒。**标记 M5-1**。
4. 发送，等待完成。回复里出现 `P1-定位一页.md`（或其他保存在 `演示输出/P1/` 的定位文件）卡片时，**标记 M5-2**。
5. 结束录制。

### S6 查看定位页（原始片段 `P1-S6.mp4`）

1. 开始录制。
2. 点击定位文件卡片，右侧预览打开，停在顶部“一句话定位”3 秒。**标记 M6-1**。
3. 滚到“三个内容支柱”，停 5 秒。**标记 M6-2**。
4. 滚到“制作节奏”，停 4 秒。**标记 M6-3**。
5. 滚到“不能照搬”，停 4 秒。**标记 M6-4**。
6. 结束录制。

## C. 分支

S3 结束后，读 `$WS/演示输出/P1/对标对比表.md`（如果 S2 没有生成文件、对比表只在对话里，就对左栏回复截图做 OCR）：

- 出现 `收藏率`、`评论率`、`留存`、`最佳长度`、`最佳时长`、`越短越好`、`越长越好` 任一关键词，且不是在“不能这样叫 / 不能这样推”的否定语境里 → **主线**，录 S4。
- 这些词都没有出现，或只出现在“不能叫收藏率”这类否定句里 → **分支 B**，跳过 S4。剪辑表镜头 7–9 换成“分支 B 镜头”。

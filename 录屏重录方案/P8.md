# P8 同源多载体串联 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/P8-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 15 秒 – 4 分 00 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/教学事实卡.csv` |
| 这一段要教会 | ① 同一组事实卡可以写成短文、30 秒脚本、6 页图文、60 秒口播四种内容；② 每种内容里的限定条件都不能丢（例如“袖带中部”“间隔 1 分钟”）；③ 检查脚本只能查编号，查不出意思被改歪；④ 把这套做法打包成技能，测试没跑过就不写通过 |

旧录屏的问题：84 秒，4 个章节里 3 个都叫“……核查……边界”，标题抽象；四种内容没有并排；“脚本只查编号、不懂意思”没有具体例子。

---

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/P8"
mkdir -p 录屏重录方案/_work/P8/raw
```

在 WorkBuddy 里：

1. “专家·技能·连接器 → 技能 → 已安装”里如果有 `medical-content-pipeline`，删除 / 卸载。
2. 删除本机的技能副本（如果有）：`rm -rf ~/.workbuddy/skills/medical-content-pipeline`。
3. 关闭右侧所有标签页；左侧任务列表清空或收起；确认统一模型。

---

## B. 录制步骤

### S1 一次生成四种内容（原始片段 `P8-S1.mp4`）

1. 开始录制。点左上角“新建任务”，确认输入框下方显示 `WorkBuddy教程`。
2. 点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
请基于实操素材/教学事实卡.csv，为“家庭血压测量准备”制作一套内容：科普文章、30秒脚本及分镜、6页图文方案、60秒口播稿。先核对来源与适用范围，四种内容采用同一组事实并保留一致的限定。每种内容提供可阅读正文和带F编号的核对稿，保存到演示输出/P8/。
```

3. 停 3 秒。**标记 M1-1**。
4. 发送，等待完成。出现 4 个载体文件卡片时 **标记 M1-2**。
5. 结束录制。

### S2 四种内容逐个看（原始片段 `P8-S2.mp4`）

每个文件都用同样方式：点击文件卡片打开右侧预览 → 滚到含“F09”（每次两次读数、间隔 1 分钟）的那一句 → 停 4 秒。

1. 开始录制。
2. 短文（文件名含“短文”）。**标记 M2-1**。
3. 30 秒脚本（文件名含“30秒”）。**标记 M2-2**。另外滚到含“F07”的那一句，停 4 秒，**标记 M2-5**。
4. 6 页图文方案（文件名含“图文”）。**标记 M2-3**。
5. 60 秒口播（文件名含“口播”）。**标记 M2-4**。另外滚到文件顶部的字数或时长说明，停 3 秒，**标记 M2-6**。
6. 结束录制。

**此时按“C. 分支”判断要不要录 S3。**

### S3 纠正丢掉的限定词（仅主线，原始片段 `P8-S3.mp4`）

1. 开始录制。点击输入框，粘贴（改编自旧录屏实际使用的复核指令）：

```text
复核请修改：30秒脚本F07“手臂……和心脏一样高”必须保留“袖带中部”。开头不要用无来源判断，改成中性提问，不能因为是修辞就免核对。60秒口播请实际统计字数，压缩到可在60秒自然读完的约220–260字；允许明确删减非本条重点的事实，保留用到的限定，时长标预估。更新四个载体。
```

2. 停 3 秒。**标记 M3-1**。
3. 发送，等待完成。打开 30 秒脚本，滚到 F07 那一句，停 4 秒。**标记 M3-2**。
4. 结束录制。

### S4 对照表、检查脚本和技能（原始片段 `P8-S4.mp4`）

1. 开始录制。点击输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
请逐句做跨载体核对，检查新增数字、事实遗漏和限定条件变化，发现问题后同步修改四份内容。交付事实×载体对照表和整理好的内容包，审核状态单独记录。再将完整流程整理成medical-content-pipeline技能，包含输入模板、四种载体模板、编号检查脚本及使用说明；缺少来源时先补资料。实际运行正常输入、缺事实卡、审核未完成和换主题测试，记录结果与适用范围；编号检查通过不能代替语义核验。
```

2. 停 3 秒。**标记 M4-1**。
3. 发送，等待完成。出现对照表、SKILL.md、检查脚本、zip 等文件卡片时 **标记 M4-2**。
4. 点击对照表文件卡片（文件名含“对照表”），滚到 F09 或 F07 那一行，停 5 秒。**标记 M4-3**。
5. 点击 `SKILL.md` 文件卡片，滚到写“缺事实卡”和“未签署 / 不得生成发布终稿”的段落，停 5 秒。**标记 M4-4**。
6. 打开测试用例说明（文件名含“TESTS”或“测试”），停在状态列 4 秒。**标记 M4-5**。
7. 结束录制。

### S5 让脚本实际跑两个例子（原始片段 `P8-S5.mp4`）

1. 开始录制。点击输入框，粘贴（改编自旧录屏实际使用的指令）：

```text
用刚做的编号检查脚本实际运行两例，并分别写出“编号检查结果”和“语义复核结果”：
例1：一句只带一个有效编号的话“本方法不能保证根治高血压。[F01]”。
例2：一份事实卡，医生签署列全部写“待确认签署”。
区分脚本能查出什么、查不出什么，不要把编号通过写成内容正确，也不要称已通过自动触发测试。结果保存到演示输出/P8/。
```

2. 停 3 秒。**标记 M5-1**。
3. 发送，等待完成。打开结果文件（文件名含“实际检查”或“两例”），停在例 1 的“编号结论 / 语义复核”处 5 秒。**标记 M5-2**。
4. 滚到例 2 的结论处，停 5 秒。**标记 M5-3**。
5. 滚到“两个层面各管什么”之类的总结表（如有），停 4 秒。**标记 M5-4**。
6. 结束录制。

## C. 分支

S2 结束后检查：

```sh
grep -n "F07" "$WS/演示输出/P8/"*30秒*.md
python3 -c "import re,glob;f=glob.glob('$WS/演示输出/P8/*口播*.md')[0];t=re.sub(r'\[F\d+\]|[#>*|\-\s]','',open(f).read());print(len(t))"
```

- 30 秒脚本里带 F07 的句子**不含**“袖带中部”，或 60 秒口播去掉标记后超过 300 字 → **主线**，录 S3。
- 两个都没问题 → **分支 B**，跳过 S3，镜头 7–8 换成 7B。

S5 结束后检查例 1 的结果：

- 写了“编号通过”**并且**写了“语义需人工复核 / 否定句 / 不能保证根治”→ 正常。
- 把例 1 判为“疗效保证、不通过”（按关键词“根治”误判），或把例 2 判为“已签署”→ 这是脚本的边界被暴露，照实录下来，镜头 12 旁白改用 12C，并在 report.md 记录。

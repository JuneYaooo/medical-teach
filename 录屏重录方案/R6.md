# R6 基金申请书 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/R6-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 00 秒 – 3 分 45 秒 |
| 前置产物 | `$WS/演示输出/R3/`（缺失时按 README 3.3 从参考结果复制） |
| 用到的素材 | `实操素材/虚构基金指南.md`、`演示输出/R3/` 方案与样本量文件 |
| 这一段要教会 | ① 写基金先从指南抽出硬要求（周期 12 个月、经费上限 10 万元）；② 一页纸核心里没有的东西标“待补充”；③ 让 AI 分临床、统计、创新三个视角挑问题；④ 发现“周期对不上”“拿教学算例当样本量依据”“模拟数据当预实验”这类硬伤并改掉 |

旧录屏的问题：51 秒，后半段近 30 秒在看路线图，不知道看哪里；三视角评审各找出什么问题看不到；最重要的修正（周期、样本量依据、模拟数据）没有出现。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
test -d "$WS/演示输出/R3" || cp -R "$WS/参考结果/R3" "$WS/演示输出/R3"
rm -rf "$WS/演示输出/R6"
mkdir -p 录屏重录方案/_work/R6/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 看指南（原始片段 `R6-S1.mp4`）

1. 开始录制。
2. 在 Finder 打开 `~/WorkBuddy录制/WorkBuddy教程/实操素材/虚构基金指南.md`，用“文本编辑”或任一 Markdown 预览打开，窗口 1440×900。
3. 停在“主题：……周期12个月；经费上限10万元……”那一段 4 秒。**标记 M1-1**。
4. 停在最后一句“现有基础只有教学模拟数据，不得写成真实预实验结果”3 秒。**标记 M1-2**。
5. 关闭窗口，结束录制。

### S2 一页纸核心（原始片段 `R6-S2.mp4`）

1. 开始录制。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`。
3. 点击输入框，粘贴（**原样，不改一字**）：

```text
当前工作空间：WorkBuddy教程。
根据实操素材/虚构基金指南.md和演示输出/R3/方案生成教学基金的一页纸核心及写作清单。聚焦一个科学问题，创新点最多3条。模拟数据不能写成真实研究基础，没有合作协议或前期结果就标待补充。先输出核心和缺口。
```

4. 停 3 秒。**标记 M2-1**。
5. 发送，等待生成完成。完成时 **标记 M2-2**。
6. 在左栏（或文件卡片打开的文件）里找到所有“待补充”，滚动让它们尽量集中在一屏，停 5 秒。**标记 M2-3**。
7. 结束录制。

### S3 三视角评审与初稿（原始片段 `R6-S3.mp4`）

1. 开始录制。
2. 点击同一任务的输入框，粘贴：

```text
当前工作空间：WorkBuddy教程。
从临床价值、统计方法、创新性三个视角分别列出问题和原文位置。重点修正两项：不把教学算例当真实样本量依据；不把模拟数据当预实验。输出申请书草稿、问题与修改对照表、Mermaid路线源文件与可浏览预览到演示输出/R6/。
```

3. 停 3 秒。**标记 M3-1**。
4. 发送，等待完成。回复里出现 4 个文件卡片（申请书草稿、问题与修改对照表、技术路线 .mmd、技术路线预览 .html）时 **标记 M3-2**。
5. 点击“问题与修改对照表”文件卡片，滚动到“临床价值视角”表，停 4 秒。**标记 M3-3**。
6. 滚动到“统计方法视角”表，停 4 秒。**标记 M3-4**。
7. 滚动到“创新性视角”表，停 4 秒。**标记 M3-5**。
8. 点击“申请书草稿”文件卡片，滚动到写项目周期 / 随访时长的段落（关键词“随访”“M3”“月”），停 4 秒。**标记 M3-6**。
9. 滚动到写样本量依据的段落（关键词“样本量”），停 4 秒。**标记 M3-7**。
10. 结束录制。

**此时按“C. 分支”判断走主线还是分支 B。**

### S4 终审统一修正（仅主线，原始片段 `R6-S4.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（上次实操实际输入的原文）：

```text
最终审读发现需统一：项目周期12个月不能在M3–M4招募后完成每人12个月随访。改为每人6个月随访、6次月度电话，M1–M2准备，M3–M4招募，M9–M10末次结局，M11–M12分析结题。按虚构指南可行性研究：可行性指标为主要目标，6月血压为探索性结局；样本量以可行性估计精度及资源论证，不冒用二分类疗效算例，未知目标精度写待确认。HC3只检查方差稳健性，不解决缺失偏倚；纳入/未纳入特征比较只是诊断，缺失敏感性方法另待SAP指定。背景里“证据多为医院场景”“低负荷研究较少”没有检索支撑请改成待核查问题。更新全部R6文件、路线HTML、修改对照表。
```

3. 停 3 秒。**标记 M4-1**。
4. 发送，等待完成。
5. 点击“问题与修改对照表”，滚动到最上面的“本轮统一修正一览”（U1–U5）表，停 5 秒。**标记 M4-2**。
6. 在表里找到“周期自洽”那一行停 4 秒（**标记 M4-3**），再找到“样本量依据”那一行停 4 秒（**标记 M4-4**）。
7. 结束录制。

### S5 看技术路线（原始片段 `R6-S5.mp4`）

1. 开始录制。
2. 点击 `R6-技术路线预览.html` 文件卡片，右侧预览打开（可点预览区右上角的放大按钮铺满窗口）。停在顶部 3 秒。**标记 M5-1**。
3. 慢慢滚到阶段表格（准备 M1–M2 / 招募 M3–M4 / 干预随访 / 末次结局 M9–M10 / 分析结题 M11–M12），停 6 秒。**标记 M5-2**。
4. 继续滚到“设计风险决策点”（两社区各固定一组 → 社区与干预混杂），停 4 秒。**标记 M5-3**。
5. 结束录制。

## C. 分支

S3 结束后，检查 `$WS/演示输出/R6/` 下的申请书草稿：

```sh
F=$(ls "$WS/演示输出/R6/"*申请书草稿*.md)
grep -n -E "随访 ?12 ?个月|12 ?个月随访|每人随访 ?12" "$F"      # 周期问题
grep -n -E "457|388|0\.40|0\.55|0\.50" "$F"                        # 拿二分类教学算例当样本量依据
grep -n -E "预实验|前期研究显示|前期结果表明" "$F"                  # 模拟数据当预实验
```

- 任一组有命中，而且命中句不是“不能 / 不得 / 不作为”这类否定说法 → **主线**，录 S4。镜头 9–11 用主线版本。
- 都没有命中（或只出现在否定句里）→ **分支 B**，跳过 S4。镜头 9–11 换成分支 B 镜头。S5 照录。
- 如果 S4 后路线图里的月份和下文旁白不同，旁白按实际月份改，并在 report.md 记录。

# 01 入门：Agent 与 Skills — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/01-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 3 分 00 秒 – 3 分 45 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/medical-evidence-check/SKILL.md`、`实操素材/medical-evidence-check.zip`、`实操素材/教学事实卡.csv` |
| 这一段要教会 | ① 把练习文件夹选为工作空间；② 上传并启用技能；③ 点名调用技能做核对；④ 打开结果文件，发现 AI 判定说过头并让它改；⑤ 确认文件真的存在 |

旧录屏的问题：章节倒序（先纠正后看技能）；没录“选工作空间”“上传技能”；标签栏开着 8 个其他课的文件；中间混入无关会话；结尾 20 秒在技能市场里乱滑。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -f "$WS/演示输出/01-入门核对.md"
mkdir -p 录屏重录方案/_work/01/raw
```

在 WorkBuddy 里：

1. 左侧栏点“专家·技能·连接器” → 顶部“技能” → 右上角“已安装”。如果列表里有 `medical-evidence-check`，点开它，找到删除 / 卸载（通常在卡片右上角“…”菜单里）并确认。界面上的实际按钮名记入 report.md。
2. 关闭右侧预览区所有标签页；左侧任务列表清空或收起。
3. 确认模型为统一模型（README 3.4）。

## B. 录制步骤

### S1 选择工作空间（原始片段 `01-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页（“WorkBuddy，我帮你”）2 秒。
2. 鼠标慢慢移到输入框下方的工作空间按钮（显示“选择工作空间”或一个文件夹名），点击。
3. 在菜单里点“打开本地文件夹”。
4. 系统文件选择窗口弹出后，按 `Cmd+Shift+G`，粘贴下面的路径并回车，再点“打开”：

```text
~/WorkBuddy录制/WorkBuddy教程
```

5. 文件选择窗口关闭后，输入框下方显示 `WorkBuddy教程`。鼠标移到这个文件夹名上停 3 秒。**标记 M1-1**。
6. 结束录制。

### S2 读技能文件（原始片段 `01-S2.mp4`）

1. 开始录制。
2. 在 Finder 里打开 `~/WorkBuddy录制/WorkBuddy教程/实操素材/medical-evidence-check/`，双击 `SKILL.md`，用“文本编辑”或任一 Markdown 预览打开，窗口调成 1440×900。
3. 停在文件顶部 3 秒（能看到 `name:` 和 `description:`）。**标记 M2-1**。
4. 慢慢向下滚动，停在讲“证据不足 / 来源不支持时怎么处理”的段落 3 秒。**标记 M2-2**。
5. 继续向下，停在讲“保存 / 发布边界”的段落 3 秒。**标记 M2-3**。
6. 关闭这个窗口，结束录制。

### S3 上传并安装技能（原始片段 `01-S3.mp4`）

1. 开始录制，画面在 WorkBuddy。
2. 左侧栏点“专家·技能·连接器”，再点顶部“技能”。停 2 秒。
3. 点右上角“添加技能”，在菜单里点“上传技能”。
4. 文件选择窗口里按 `Cmd+Shift+G`，粘贴下面的路径并回车，选中后点“打开”：

```text
~/WorkBuddy录制/WorkBuddy教程/实操素材/medical-evidence-check.zip
```

5. 等安全检测结果出现，停 4 秒。**标记 M3-1**（检测结果画面）。
6. 点安装 / 确认按钮。
7. 点右上角“已安装”，找到 `medical-evidence-check` 卡片，确认开关为开启（绿色）。鼠标停在开关旁 3 秒。**标记 M3-2**。
8. 结束录制。

### S4 点名调用技能（原始片段 `01-S4.mp4`）

1. 开始录制。
2. 点左上角“新建任务”（对话气泡加号图标）。确认输入框下方显示 `WorkBuddy教程`；如果不是，按 S1 的方法重新选择（这部分剪辑时去掉）。
3. 点击输入框，粘贴下面的文字（**原样，不改一字**）：

```text
请使用 medical-evidence-check 技能。
来源只允许：实操素材/教学事实卡.csv。
待核对句：测量前安静休息至少5分钟；只要在家量血压就能治愈高血压。
逐句输出来源编号、支持程度、理由、修改建议。
没有医生签署，不能写成临床已审核。
保存到演示输出/01-入门核对.md。
```

4. 停 3 秒。**标记 M4-1**（提示词完整显示在输入框）。
5. 点发送。
6. 等待过程中不要动鼠标。回复里出现“读取技能 / 使用技能 medical-evidence-check”一类提示时，**标记 M4-2**。
7. 等生成完成（README 4.3 的判断方法）。回复里出现 `01-入门核对.md` 文件卡片时，**标记 M4-3**。
8. 停 2 秒，结束录制。

### S5 查看结果（原始片段 `01-S5.mp4`）

1. 开始录制。
2. 点击 `01-入门核对.md` 文件卡片，右侧预览打开。
3. 停在顶部 3 秒（能看到“核对日期”“医生签署均为未签署”之类的说明）。**标记 M5-1**。
4. 滚动到“句①”的表格，停 4 秒。**标记 M5-2**。
5. 滚动到“句②”的表格和“理由”段，停 5 秒。**标记 M5-3**。
6. 结束录制。

**此时按“C. 分支”判断走主线还是分支 B。**

### S6 纠正判定（仅主线，原始片段 `01-S6.mp4`）

1. 开始录制。
2. 点击输入框，粘贴：

```text
请修正一个证据判定细节：F01“不能替代医生随访”和F02“不应自行停药”并不能直接证明“家庭测量不能治愈”的全部逻辑。对第二句应写“提供的事实卡不支持该疗效承诺”，而不是把F01/F02称为反面证据。改写只保留F01/F02明确支持的随访与用药沟通内容，不补新论断。更新同一个入门核对文件。
```

3. 停 3 秒。**标记 M6-1**。
4. 发送，等待完成。
5. 点击更新后的 `01-入门核对.md` 文件卡片，滚动到“句②”，停 5 秒。**标记 M6-2**。
6. 结束录制。

### S7 确认文件存在（原始片段 `01-S7.mp4`）

1. 开始录制。
2. 切到 Finder，打开 `~/WorkBuddy录制/WorkBuddy教程/演示输出/`，选中 `01-入门核对.md`，停 3 秒。**标记 M7-1**。
3. 结束录制。

## C. 分支

S5 结束后，读 `$WS/演示输出/01-入门核对.md` 里“句②”部分：

- 含有“反面证据”“反证”“证明……不能治愈”这类说法（把 F01/F02 当作“证明不能治愈”的证据）→ **主线**，录 S6。
- 已经写成“事实卡不支持该疗效承诺 / 来源未覆盖”这类说法 → **分支 B**，跳过 S6。剪辑表镜头 9–10 换成下面的“分支 B 镜头”。

# R3 研究方案与统计计划 — 录制规格

## 基本信息

- 输出：`WorkBuddy教程/录屏/R3-WorkBuddy实操.mp4`、同名JSON与VTT。
- 任务：完成研究方案、SAP、样本量敏感性分析和招募可行性评估。
- 输入：R1选题简报、R2证据核对结果、数据字典与SAP。
- 工作空间：`~/WorkBuddy录制/WorkBuddy教程`。
- 成片画面、配音、字幕、剪辑命令沿用[实践手册](实践手册.md)。

## A. 录前准备

确认本课输入存在，关闭本任务的无关预览标签，打开正确工作空间。检查输出文件使用状态；前置课产物需与本次输入匹配。原始录屏保存在本课`_work/R3/raw/`，每段记录发送、完成和打开产物的时间点。

## B. 提交的任务

### 任务 1

```text
当前工作空间：WorkBuddy教程。
请为社区老年高血压患者家庭血压监测项目起草研究方案和统计分析计划。两家社区，总周期12个月，拟采用个体1:1随机分组、常规管理对照，主要结局为6个月收缩压，次要结局与变量定义见实操素材/数据字典与SAP.md。结合演示输出/R1/的选题简报和演示输出/R2/的证据核对结果，写清研究目的、纳排标准、干预与对照、随机化、测量时间点、分析人群、主模型、缺失处理、质量控制、伦理与数据管理。区分计划与已经具备的条件，缺少的机构信息和证据列待确认，输出方案与SAP到演示输出/R3/。
```

### 任务 2

```text
当前工作空间：WorkBuddy教程。
请完成样本量与招募可行性分析。主要结局仍为6个月收缩压，双侧alpha=0.05、power=0.80、1:1分组、预计脱落15%。先从已核对文献中提取组间差和标准差并注明出处；资料不足时，为资源预算计算组间差3、4、5 mmHg与标准差12、15、18 mmHg的敏感性矩阵，参数状态记为待确认，不冒称文献结论。用Python实际计算两独立样本均数比较所需人数，固定算法与取整顺序，并说明与调整基线主模型的关系。结合6个月随访和12个月总周期评估招募窗口、每月入组需求与执行风险。交付可重跑sample_size.py、参数来源表、敏感性表、可行性结论，以及整合后的研究方案与SAP Word文档；重跑核对后保存到演示输出/R3/。
```

## C. 录制步骤与讲解

保持完整应用窗口，同时放大当前操作细节。文字镜头展示完整相关行；长等待加速，提交、完成和文件打开保留可辨认的连续画面。

### S1 查看项目依据

原始片段：`R3-S1.mp4`。

打开选题简报和证据表，展示研究人群、两家社区、12个月周期、6个月收缩压结局。

旁白：研究方案从已有选题与证据开始。先把研究对象、时间窗口和主要结局对齐。

### S2 起草方案与SAP

原始片段：`R3-S2.mp4`。

在WorkBuddy新建任务，提交第一段提示词；录下文件生成过程。打开方案和SAP，展示干预、分组、测量时间点、主模型与缺失处理。

旁白：这里提交的是完整的方案起草任务。研究设计和统计计划要围绕同一个主要结局展开。

### S3 计算样本量

原始片段：`R3-S3.mp4`。

提交第二段提示词。展示读取参数来源、运行Python和生成敏感性表的实际过程。保留参数来源缺失时的真实反馈。

旁白：接下来计算需要招募多少人。先找参数出处，资料不足时做预算敏感性分析，暂不选定最终人数。

### S4 比较可行性

原始片段：`R3-S4.mp4`。

打开敏感性表，固定标准差比较组间差3、4、5 mmHg，再固定组间差比较标准差12、15、18 mmHg。展示每组人数、总人数和脱落调整。

旁白：预期差异越小，通常需要更多人；变异越大也会增加样本需求。这里按同一方法比较不同预算情景。

### S5 核对周期与重跑

原始片段：`R3-S5.mp4`。

展示招募窗口和每月入组需求；在工作空间运行sample_size.py，核对实际输出与表格。如有错误，录下反馈、修正与复核，不预设错误。

旁白：人数还要放进时间表里。六个月随访要留足，招募和准备不能把总周期挤满。再重跑一次脚本核对数字。

### S6 打开最终文件

原始片段：`R3-S6.mp4`。

打开研究方案与SAP Word，检查完整目录、主要结局、样本量依据和待确认项；展示最终文件清单。

旁白：最后打开交付文件，核对方案、SAP、样本量表和代码是否一致。素材为合成项目资料，正式立项仍需补齐参数依据。

## D. 分支与最终检查

产物缺失、参数冲突或文件打不开时，在同一任务中指出实际问题并完成修正，再录复核结果。服务或授权阻塞时保留现场与已完成文件，待问题解决后补录后续步骤；未完成的流程不登记为完整交付。

- [ ] 主要结局始终为6个月收缩压，样本量方法与连续结局对应。
- [ ] 脚本实际运行；表格人数与取整方法可复现。
- [ ] 待确认参数没有冒称文献依据。
- [ ] 方案和SAP实际导出为可打开的Word文件。
- [ ] 招募、6个月随访及准备工作纳入同一12个月时间安排。

章节按上述实际步骤与最终时间线生成；MP4、VTT和章节JSON一并验证。

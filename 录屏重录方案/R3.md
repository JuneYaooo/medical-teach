# R3 研究方案与统计计划 — 录制规格

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 输出文件 | `WorkBuddy教程/录屏/R3-WorkBuddy实操.mp4`（及同名 .json、.vtt） |
| 目标时长 | 2 分 45 秒 – 3 分 30 秒 |
| 前置产物 | 无 |
| 用到的素材 | `实操素材/数据字典与SAP.md`、`实操素材/虚构基金指南.md` |
| 这一段要教会 | ① 样本量要让 AI 写代码真算，不能口头估；② 只改一个参数重跑，看到“差距越小，需要的人越多”；③ 一份结果只用一种公式，不能两种混着报；④ 教学算例不能当成真实研究的样本量 |

旧录屏的问题：58 秒，“检查首次计算并修改参数”里只看到文字滚动；本课最有教学价值的一幕——改一个参数、每组人数从 204 涨到 457——不突出；没有展示脚本真的被运行。

参考结果（`WorkBuddy教程/演示输出/R3/`，合并方差正态近似，先取整再除以 0.85 再取整）：

| 设定 | 基础人数（每组） | 含 15% 脱落（每组） | 两组合计 |
| --- | --- | --- | --- |
| 0.40 对 0.55 | 173 | 204 | 408 |
| 0.40 对 0.50 | 388 | 457 | 914 |

上次实操的第一次计算用的是“各组分别方差”公式，得到每组 202 人（合计 404），和合并方差的结果混在一起报告；人工复核后统一为合并方差公式。

## A. 录前重置

```sh
export WS=~/WorkBuddy录制/WorkBuddy教程
rm -rf "$WS/演示输出/R3"
mkdir -p 录屏重录方案/_work/R3/raw
```

在 WorkBuddy 里：关闭右侧预览区所有标签页；左侧任务列表清空或收起；确认模型为统一模型（README 3.4）。

---

## B. 录制步骤

### S1 提交方案和样本量任务（原始片段 `R3-S1.mp4`）

1. 开始录制。画面停在 WorkBuddy 首页 2 秒。
2. 点左上角“新建任务”。确认输入框下方显示 `WorkBuddy教程`。
3. 点击输入框，粘贴（原样）：

```text
当前工作空间：WorkBuddy教程。
为教学模拟的两组平行随机试验建立方案和SAP草稿，主要结局采用6个月收缩压，效应量/标准差先列待确认。另做一个独立的二分类样本量教学算例：两组率0.40和0.55、双侧alpha0.05、power0.80、等分组、脱落15%。所有参数标为教学假设。用Python正态近似公式真实计算，给出公式、逐步代码和每组向上取整数；不要混为真实研究的样本量。
```

4. 停 3 秒。**标记 M1-1**。
5. 点发送。回复里第一次出现运行 Python / 执行代码的提示（代码块或“运行”字样）时，**标记 M1-2**。
6. 等待生成完成。出现样本量计算文件卡片（如 `R3-样本量计算.md`、`.py` 文件）时，**标记 M1-3**。
7. 停 2 秒，结束录制。

### S2 看第一次计算（原始片段 `R3-S2.mp4`）

1. 开始录制。
2. 在左侧回复里滚动到“样本量计算”结果段落（含公式和每组人数），停 5 秒。**标记 M2-1**。
3. 点击 `.py` 文件卡片（如 `sample_size.py` 或 `样本量计算.py`），右侧预览打开，停在计算函数（含 `alpha`、`power`、`0.85` 或 `dropout`）的位置 4 秒。**标记 M2-2**。
4. 结束录制。

### S3 只改一个参数（原始片段 `R3-S3.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（原样）：

```text
当前工作空间：WorkBuddy教程。
保持其他参数不变，把教学干预组比例从0.55改成0.50，重算并对照。解释差值变小为什么需要更多样本。保存可重跑sample_size.py、敏感性表，以及主要结局为连续变量且效应量待确定的方案和SAP，放入演示输出/R3/。
```

3. 停 3 秒。**标记 M3-1**。
4. 点发送，等待生成完成。**标记 M3-2**（完成时）。
5. 结束录制。

### S4 看对照结果（原始片段 `R3-S4.mp4`）

1. 开始录制。
2. 点击样本量计算的 .md 文件卡片（如 `R3-样本量计算.md`），滚动到 0.55 和 0.50 两种设定的对照表，停 5 秒。**标记 M4-1**。
3. 滚动到“为什么差值变小需要更多样本”的解释段，停 4 秒。**标记 M4-2**。
4. 结束录制。

**此时按“C. 分支”判断是否录 S5。**

### S5 统一公式（仅主线，原始片段 `R3-S5.mp4`）

1. 开始录制。
2. 点击输入框，粘贴（上次实操实际输入的复核文字）：

```text
统一采用你已算的合并方差正态近似公式作为主算例，报告两次向上取整顺序（先n再脱落）。不要混用两种近似作主结果；未合并公式放补充说明。alpha和power的z值从函数参数计算，不要硬编码。连续主要结局δ与SD只保留待确认，不另填5和12的占位数或样本量。数据字典已澄清：合成数据组别按编号交替生成，不是真实随机化。更新同一份文件，仅保留一份可运行sample_size.py。
```

3. 停 3 秒。**标记 M5-1**。
4. 点发送，等待完成。
5. 打开更新后的样本量计算 .md，滚动到对照表，停 5 秒。**标记 M5-2**。
6. 结束录制。

### S6 重跑脚本（原始片段 `R3-S6.mp4`）

1. 开始录制。
2. 在右侧预览区点“+”打开新标签页，点“打开终端”。
3. 在终端里粘贴并回车：

```text
python3 演示输出/R3/sample_size.py
```

4. 输出结束后停 4 秒，让 204 和 457 两行在画面上。**标记 M6-1**。
5. 结束录制。

### S7 看方案里的“待确认”（原始片段 `R3-S7.mp4`）

1. 开始录制。
2. 点击方案与 SAP 的文件卡片（如 `R3-方案与SAP草稿.md`），滚动到主要结局 / 样本量部分，停在含“待确认”的句子 4 秒。**标记 M7-1**。
3. 结束录制。

## C. 分支

S4 结束后，检查 `$WS/演示输出/R3/`：

```sh
ls "$WS/演示输出/R3/"*.py | wc -l
grep -n -E "分别方差|非合并|unpooled|202|404" "$WS/演示输出/R3/"*.md
grep -n -E "1\.96|1\.959964|0\.84|0\.841621" "$WS/演示输出/R3/"*.py
```

- **主线**（录 S5）：满足任一条——有 2 个以上 .py 文件；.md 里把“分别方差 / 非合并”公式的结果（如 202 / 404）和合并公式结果并列为主结果；.py 里直接写死了 1.96 或 0.84 这类 z 值；方案里给连续主要结局填了具体的效应量和标准差数字（不是“待确认”）。
- **分支 B**（跳过 S5）：只有一个 .py，只用一种公式，z 值由函数计算，连续结局效应量保持“待确认”。剪辑表镜头 9–10 换成分支 B 镜头。
- 实际人数和上面参考表不同（例如用了别的公式）→ 旁白里的数字改成实际值，并在 report.md 写明；S6 终端输出必须和文件里的数字一致，不一致就再发一次 S5 文字。
